# Нарезки со стримов (GTA 6 и не только)

Делает из стримов вертикальные ролики для TikTok, Shorts и Reels: вебка сверху, игра снизу, крупные субтитры
по словам (текущее слово подсвечено), заголовок-хук и подпись канала стримера. Громкость выровнена под площадки
(−14 LUFS).

Работает с Twitch и YouTube. Способы:

| Команда | Что делает | Когда брать |
| --- | --- | --- |
| `streamers` | кто сейчас стримит GTA 6 на Twitch и YouTube, по числу зрителей | понять, кого резать |
| `top-clips` | самые просматриваемые клипы категории GTA VI на Twitch за последние часы → готовые вертикальные ролики | быстрее всего: зрители уже нашли лучшие моменты |
| `youtube-top` | самые просматриваемые записи стримов GTA 6 на YouTube за сутки, из каждой лучшие моменты | YouTube на автомате |
| `auto` | качает звук и чат записи стрима, находит горячие моменты, качает только эти куски и режет их | эксклюзив: моменты, которые ещё никто не нарезал |

## Установка (один раз)

1. Python 3.10 или новее: https://www.python.org/downloads/ (на Windows отметь «Add python.exe to PATH»).
2. ffmpeg: на Windows `winget install ffmpeg`, на macOS `brew install ffmpeg`, на Linux `sudo apt install ffmpeg`.
3. Библиотеки:

```bash
pip install -r clips/requirements.txt
```

Первый ролик с субтитрами скачает модель Whisper `small` (около 500 МБ). С видеокартой NVIDIA всё работает
быстрее само.

### Ключи Twitch (5 минут, бесплатно, очень желательно)

Без ключей поиск идёт через внутренний API сайта Twitch, который могут закрыть в любой день.
С ключами `top-clips` берёт топ клипов всей категории сразу, а не по каналам.

1. Зайди на https://dev.twitch.tv/console/apps, нажми «Register Your Application».
2. Name: любое, OAuth Redirect URL: `http://localhost`, Category: Application Integration, Client Type: Confidential.
3. Открой приложение: скопируй Client ID, нажми «New Secret» и скопируй секрет.
4. Создай файл `clips/keys.json` (он в `.gitignore`, в git не попадёт):

```json
{"TWITCH_CLIENT_ID": "...", "TWITCH_CLIENT_SECRET": "...", "YOUTUBE_API_KEY": ""}
```

Ключ YouTube нужен только для точного числа зрителей у эфиров YouTube (Google Cloud Console → YouTube Data API v3 →
Credentials → API key). Без него поиск идёт через yt-dlp.

## Как пользоваться

Все команды запускаются из папки репозитория. Ролики появляются в `clips_out/`, рядом с каждым `.json`
с текстом речи (пригодится для описания) и ссылкой на источник.

Кто сейчас стримит GTA 6 по-русски (список со ссылками сохраняется в `clips_work/streamers.csv`):

```bash
python clips/clip.py streamers --lang ru
```

Все языки, ещё и GTA V (РП-серверы):

```bash
python clips/clip.py streamers --lang "" --game "Grand Theft Auto VI" --game "Grand Theft Auto V"
```

10 самых популярных русских клипов GTA 6 за сутки в вертикальные ролики:

```bash
python clips/clip.py top-clips --hours 24 --lang ru --top 10
```

Только каналы, которые разрешили нарезки:

```bash
python clips/clip.py top-clips --channels streamer1,streamer2 --hours 12
```

3 самые просматриваемые записи стримов GTA 6 на YouTube за сутки, по 3 лучших момента из каждой
(моменты ищутся по чату, голосу и графику пересмотров; `--query "гта 6 стрим"`, чтобы найти русские):

```bash
python clips/clip.py youtube-top --streams 3 --render-top 3
```

Чат длинного стрима YouTube качается несколько минут; `--no-chat` быстрее, тогда моменты ищутся по голосу
и пересмотрам.

Найти моменты в записи стрима и сразу нарезать 5 лучших:

```bash
python clips/clip.py auto "https://www.twitch.tv/videos/1234567890" --render-top 5
```

Последняя запись канала:

```bash
python clips/clip.py auto twitch:имя_канала
```

Сначала посмотреть моменты, потом выбрать. `moments` пишет `clips_work/<запись>/moments.md` со ссылками на каждый
момент; в `moments.json` можно вписать заголовок в поле `"title"`:

```bash
python clips/clip.py moments "https://www.youtube.com/watch?v=..."
```

```bash
python clips/clip.py render --moments clips_work/<запись>/moments.json --pick 1,3,4
```

Кусок по времени, со своим заголовком:

```bash
python clips/clip.py render "https://www.twitch.tv/videos/1234567890" --start 1:23:45 --len 30 --title "КОГДА КОПЫ В GTA 6 НЕ ШУТЯТ"
```

Работает и с файлом на диске (например, записью из OBS): вместо ссылки укажи путь к `.mp4`.

### Оформление

- `--layout split` вебка сверху, игра снизу (выбирается само, если вебка найдена);
  `blur` весь кадр по центру на размытом фоне; `crop` центр кадра 9:16 (стример во весь кадр).
- Вебка ищется сама по лицу и рамке. Найденный прямоугольник рисуется в `clips_work/.../<ролик>.cam.jpg`.
  Если промахнулся, задай вручную: `--cam 0,700,480,270` (x, y, ширина, высота в пикселях исходника).
- `--zoom 1.2` приблизить игру, `--game-x 0.4` сдвинуть кадр игры влево.
- `--censor` прячет мат: в субтитрах звёздочки (`б**ть`), в звуке писк поверх слова (по таймингу Whisper).
  `--no-bleep` оставляет звук как есть.
- `--model large-v3-turbo` точнее субтитры (медленнее без видеокарты), `--no-subs` без субтитров.
- `--title-secs 4` заголовок только первые 4 секунды, `--no-credit` без подписи канала.
- `--teaser` крючок: самые громкие 2 секунды ролика (крик, реакция, развязка) идут первыми, потом ролик с начала.
  Зритель в ленте сразу видит, ради чего смотреть. Если пик и так в первых 3 секундах, крючок не добавляется.

## Как находятся моменты

Каждая секунда стрима получает оценку из трёх сигналов, каждый сравнивается с обычным уровнем этого же стрима
за последние минуты:

- **Голос**: насколько громче обычного стример (полоса голоса 250–3500 Гц, чтобы взрывы и музыка мешали меньше):
  крик, смех, паника.
- **Чат**: во сколько раз чат пишет чаще обычного; смех (`KEKW`, `ахаха`, `ору`), хайп (`жесть`, `POG`, `???`)
  и особенно «клип» весят больше. Чат сдвигается назад на `--lag 5` секунд: он реагирует с опозданием.
- **Пересмотры YouTube**: график «самые популярные фрагменты», если у видео он есть.

Без чата голос легко путается с самой игрой: кричат и персонажи, и взрывы. Поэтому в этом случае (`--rerank auto`)
кандидатов берётся втрое больше, Whisper распознаёт речь в каждом, и выше поднимаются те, где стример реагирует:
смех, «что?!», «жесть», мат, восклицания, быстрая речь. Тихие куски и куски без слов опускаются. Текст каждого
момента пишется в `moments.json` (поле `text`): по нему удобно придумывать заголовки.

Первые секунды решают: в первых роликах канала их досматривали 70–78% там, где фраза звучала сразу, и 16–23% там,
где ролик начинался с затишья. Поэтому после распознавания речи ролик обрезается: начало за 0,3 с до первого слова,
конец через 0,8 с после последнего. Длинную паузу внутри (например, 15 секунд тишины до главной фразы) это не
убирает: такой момент лучше перерезать вручную через `render --start`, глядя на текст в `.ass` рядом с роликом.

Ролик начинается за ~23 секунды до пика (`--len 35`: 65% до, 35% после), чтобы было видно, с чего всё началось,
а края сдвигаются в паузы речи, чтобы не резать слово пополам. Первые 3 минуты стрима (`--skip-start 180`)
пропускаются: там обычно заставка.

Чат Twitch качается через внутренний API сайта. Если Twitch его поменял, скачай чат программой
[TwitchDownloader](https://github.com/lay295/TwitchDownloader) (`TwitchDownloaderCLI chatdownload --id <номер записи>
-o chat.json`) и передай `--chat chat.json`. Без чата моменты ищутся по голосу.

## Чтобы росли охваты

- Скорость решает: в первые дни после релиза один и тот же момент режут десятки каналов, и раньше выложенный ролик
  забирает просмотры. Запускай `top-clips --hours 6` и `youtube-top` несколько раз в день.
- Первая секунда и заголовок: вопрос или обещание («ОН НЕ ОЖИДАЛ ЭТОГО ОТ КОПОВ»), а не «смешной момент».
- 20–40 секунд, 3–5 роликов в день, хэштеги `#gta6 #гта6 #гта #стрим` и ник стримера.
- Радио в машинах GTA с лицензионной музыкой: YouTube может поставить заявку Content ID, TikTok иногда глушит звук.
  Моменты без радио безопаснее.

Не выкладывай моменты с оскорблениями по полу, национальности и т. п.: площадки удаляют такие ролики, а канал
получает страйк. Текст в `moments.json` помогает заметить такое до рендера.

## Публикация на YouTube (правила канала)

- **Заголовок понятен за секунду**: что происходит + стример + «GTA 6» («Копы на хвосте? Переоденься! Эдисон в GTA 6»),
  а не голая цитата. Первая строка описания начинается с поисковой фразы («Смешной момент GTA 6: …»). Теги:
  gta 6, гта 6, приколы гта 6, смешные моменты gta 6, gta 6 стрим, ник стримера. Ролики не удалять и не перезаливать:
  первые показы в Shorts приходят волнами через 6–48 часов.
- **Описание без ссылок.** Пока канал не прошёл расширенную проверку, YouTube подсвечивает описание со ссылкой красным
  и не даёт сохранить правки в Studio. Формат: одна строка с цитатой или сутью момента, пустая строка, хэштеги
  (`#gta6 #гта6 #gta #<стример> #shorts`). Ник стримера есть в заголовке и на самом ролике (подпись канала).
- **Аудитория «не для детей».** vidIQ это поле не передаёт, поэтому на канале должна стоять настройка по умолчанию:
  Studio → Настройки → Канал → Расширенные настройки → Аудитория → «Нет, этот канал не предназначен для детей».
  Возрастное ограничение оставлять «подходит для зрителей младше 18».
- **Частота**: 4 ролика в день, каждые 3 часа (13:00, 16:00, 19:00, 22:00 МСК), разные стримеры подряд. При 6–9
  роликах в день по полчаса они отбирали показы друг у друга, после первых трёх показы упали до 0–40.
- **Заголовок по кадрам**: перед заголовком смотреть ленту кадров (0.5, 4, 9, 14, 19, 25, 31 с) и расшифровку:
  заголовок говорит, что на самом деле происходит на экране.
- **Время публикации** в vidIQ должно быть минимум ~30 минут вперёд, иначе черновик не проходит («publishAt must be
  in the future»). Если слот уже прошёл, публиковать сразу (без времени, public).
- **Что брать**: действие, понятное без контекста (копы, погони, драки, фейлы, реакция на графику). «Копы на хвосте»
  удержал 84% зрителей; ролики-разговоры («как сесть?») пролистывали.
- **Время**: первые ночные ролики (после 23:00 МСК) почти не получили показов, лучшее время 12:00–22:00 МСК. Владелец
  канала разрешил выкладывать и ночью, ради количества, пока GTA 6 на пике.
- **Канал подтверждён по телефону**: без этого YouTube после ~10 загрузок в сутки отвечает `uploadLimitExceeded`.

## Права

Это чужой контент. Бери стримеров, которые разрешают нарезки (многие пишут это в описании канала или платят
клиперам за просмотры), всегда оставляй подпись канала (она добавляется сама) и ссылку в описании. YouTube и TikTok
режут монетизацию «переиспользованного контента»; субтитры, заголовок и свой монтаж помогают, но не гарантируют.
Если стример просит удалить ролик, удаляй.

## Проверка

```bash
python clips/tests/selftest.py
```

Собирает 4-минутный ненастоящий стрим (фон, лицо в рамке в углу, три крика, всплески чата) и проверяет, что
моменты найдены, вебка найдена с точностью до 24 пикселей, ролики 1080×1920 со звуком, мат замаскирован.
Нужен `pip install scikit-image` (фото для вебки) или `--face фото.png`. Сеть и Whisper не нужны.

## Устройство

- `clip.py` команды; `discover.py` поиск стримов, клипов и записей (Twitch Helix или GraphQL сайта, YouTube API или yt-dlp);
- `source.py` ссылка или файл: сведения, звук, чат, куски видео (yt-dlp `--download-sections`);
- `chat.py` чат Twitch, TwitchDownloader, YouTube и вес сообщений; `moments.py` сигналы и выбор моментов;
- `layout.py` поиск вебки и фильтры ffmpeg для раскладок; `subs.py` Whisper и субтитры ASS; `render.py` сборка ролика;
- `fonts/` шрифт Russo One (SIL Open Font License, текст лицензии рядом).
