# Залип Лаб

Пять «залипательных» симуляций для вертикальных роликов (TikTok, Reels, Shorts), сделанных по образцу Ring Lab: превью в телефоне, слайдеры, сид, подбор сида под нужную длину и запись ролика прямо из браузера.

| Лаборатория | Что происходит | Вопрос в ролике |
| --- | --- | --- |
| Гонка шариков | 2–8 шариков катятся по трассе, собранной из сида: рампы, пеги, крутилки, отбойники | Кто придёт первым? |
| Война цветов | Шарики перекрашивают чужие клетки и отскакивают, 2–4 команды | Какой цвет захватит поле? |
| Растущий шар | Шарик прыгает в круге и растёт с каждым ударом | Заполнит ли шарик весь круг? |
| Размножение | Каждый отскок может породить новый шарик, пока не наберётся лимит | Каждый отскок = новый шарик |
| Маятники | Маятниковая волна: разные периоды, змейки и снова линия в конце цикла | Смотри, как они снова сойдутся |

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173. Ссылка на конкретную лабораторию: `#race`, `#war`, `#grow`, `#split`, `#pendulum`.

## Как сделать ролик

1. Выбери лабораторию и покрути слайдеры. Карточка под кнопками сразу пересчитывает всю симуляцию и показывает длину ролика.
2. «Найти сид» перебирает сиды и берёт тот, что ближе всего к 18 секундам (в «Войне цветов» тот, где финиш самый близкий).
3. Включи звук, если нужны ноты в ролике.
4. «Записать ролик» перезапускает симуляцию и пишет видео 1080×1920 до финальной карточки. Chrome сохраняет MP4, остальные браузеры могут дать WebM.

Одинаковые сид и настройки всегда дают одинаковый ролик: физика идёт с фиксированным шагом 1/120 с.

## Устройство

- `src/engine.js`: размер кадра, фиксированный шаг, сидированный random, звук, подпись сверху и финальная карточка.
- `src/toys/*.js`: по файлу на лабораторию. Каждая описывает свои слайдеры и возвращает симуляцию с `step`, `draw`, `pills`, `banner`, `summary`.
- `src/main.js`: страница, слайдеры, подбор сида и запись.
- `npm run artifact` собирает всё в один файл `artifact.html`.
