# Залип Лаб

Шесть «залипательных» симуляций для вертикальных роликов (TikTok, Reels, Shorts), сделанных по образцу Ring Lab: превью в телефоне, слайдеры, сид, подбор сида под нужную длину и запись ролика прямо из браузера.

| Лаборатория | Что происходит | Вопрос в ролике |
| --- | --- | --- |
| Кольца | Шарик выбирается из вращающихся колец со щелями | Сможет ли шарик выбраться? |
| Гонка шариков | 2–8 шариков катятся по трассе, собранной из сида: рампы, пеги, крутилки, отбойники | Кто придёт первым? |
| Война цветов | Шарики перекрашивают чужие клетки и отскакивают, 2–4 команды | Какой цвет захватит поле? |
| Растущий шар | Шарик прыгает в круге и растёт с каждым ударом | Заполнит ли шарик весь круг? |
| Размножение | Каждый отскок может породить новый шарик, пока не наберётся лимит | Каждый отскок = новый шарик |
| Маятники | Маятниковая волна: разные периоды, змейки и снова линия в конце цикла | Смотри, как они снова сойдутся |

## Битва ×3 и Микс ×3

- **Битва ×3** (в Кольцах, Растущем шаре и Размножении): три дорожки одной игрушки с разными сидами. Зрители угадывают в комментариях, кто финиширует первым. «Найти фотофиниш» подбирает тройку сидов, где победитель приходит около 18 секунды, а второй отстаёт на 0,15–0,4 с.
- **Микс ×3**: в каждой дорожке своя игрушка (выбирается списком), у каждой свои правила, финиш общий.
- В конце битвы вопрос сверху сменяется ответом («Победил №2»), у дорожек появляются места и отставание.

## Ноты на отскоках

Каждый удар может играть следующую ноту песни: Коробейники (Тетрис), Ода к радости, К Элизе, В лесу родилась ёлочка, Калинка. Все мелодии в общественном достоянии. Инструменты: маримба, колокольчик, 8-бит, мягкий.

## Запуск

```bash
npm install
npm run dev
```

Открой http://localhost:5173. Ссылка на конкретную лабораторию: `#rings`, `#race`, `#war`, `#grow`, `#split`, `#pendulum`, `#mix`; битва открывается с `-x3`, например `#rings-x3`.

## Как сделать ролик

1. Выбери лабораторию и покрути слайдеры. Карточка под кнопками сразу пересчитывает всю симуляцию и показывает длину ролика.
2. «Найти сид» перебирает сиды и берёт тот, что ближе всего к 18 секундам (в «Войне цветов» тот, где финиш самый близкий).
3. Включи звук, если нужны ноты в ролике.
4. «Записать ролик» перезапускает симуляцию и пишет видео 1080×1920 до финальной карточки. Chrome сохраняет MP4, остальные браузеры могут дать WebM.

Одинаковые сид и настройки всегда дают одинаковый ролик: физика идёт с фиксированным шагом 1/120 с.

## Устройство

- `src/engine.js`: размер кадра, фиксированный шаг, сидированный random, звук, подпись сверху и финальная карточка.
- `src/toys/*.js`: по файлу на лабораторию. Каждая описывает свои слайдеры и возвращает симуляцию с `step`, `draw`, `pills`, `banner`, `summary`.
- `src/battle.js`: три дорожки в одном кадре, подбор фотофиниша, микс разных игрушек.
- `src/melody.js`: мелодии, инструменты и курсор «следующая нота».
- `src/main.js`: страница, слайдеры, режимы, подбор сида и запись.
- `npm run artifact` собирает всё в один файл `artifact.html`.

# Тренд Студия

Вторая страница в этом же репозитории: `studio.html`. Три формата, которые держатся на комментариях и пересмотрах (главные сигналы алгоритма Shorts, Reels и TikTok в 2026), и всё так же без съёмки.

| Формат | Что в кадре | Зачем зрителю комментировать |
| --- | --- | --- |
| Битва месяцев | 12 шариков (месяцы рождения, знаки зодиака, буквы имени или свой список) в кольце с вращающимся выходом. Вылетел значит выбыл, последний внутри побеждает | Каждый ищет свой месяц и пишет, на каком месте он вылетел |
| Найди лишнее | Лестница уровней: сетка с одним отличающимся оттенком, буквой (Ш/Щ), цифрой (6/9) или эмодзи, таймер и ответ в кружке | Ставят паузу, пересматривают, пишут, на каком уровне сдались |
| Стоп-кадр | Пауза-челлендж: подсветка прыгает по 12 карточкам («останови видео и узнай свой ужин»), а 💎 мелькает всего на пару кадров | Пишут, что выпало, и ловят джекпот на пересмотре |

Запуск: `npm run dev` и открыть http://localhost:5173/studio.html (`#survive`, `#odd`, `#pause`). Один файл со всей студией: `npm run artifact:studio` соберёт `studio-artifact.html`.
