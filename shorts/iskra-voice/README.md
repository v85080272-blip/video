# Голос Искры

Синтетический женский голос ведущей Искры. Он создан Qwen3-TTS VoiceDesign (модель
`qwen-talker-1.7b-voicedesign-Q8_0.gguf`) по описанию:

> female, young adult, warm and soft, medium pitch, lively, friendly, smiling

Это ничей реальный голос. Владелец канала выбрал его 11.11 из трёх вариантов («второй голос хороший»); два других —
«яркий» и «пониже».

- `ref.wav` — образец, 10,7 с, 24 кГц, моно. Сделан с `--seed 7`.
- `ref.txt` — его текст.

Образец служит опорой для базовой модели, как образец рассказчика: во всех дублях получается тот же голос. В
`voice/takes.sh` выпуска с Искрой укажите:

```bash
REF=/home/user/video/shorts/iskra-voice
```

Голос Искры медленнее рассказчика, поэтому фразы обычно идут в темпе 1,1 (`"tempo": 1.1` в `voice/script.json`, тон
не меняется).
