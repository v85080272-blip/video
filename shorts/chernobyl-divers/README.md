# «Трое под реактором» — история с картинками (Чернобыль, май 1986)

Вертикальный ролик 1080×1920, 60 к/с, 44,9 с. Первая история, где кадры нарисовал Codex на компьютере владельца
(подписка ChatGPT), а сессия Claude Code там же запушила их в ветку: `img/01.png … 10.png` (коммит `8188ade`).
Запросы — `CODEX.md`, раскадровка и факты — `SHOTS.md`. Сборка — на основе «Корабль раздавило льдом»
(`../history-endurance`): медленная камера по картинкам, рассказчик, субтитры по словам, плашки, «Стоп» с двумя кнопками
и отсчётом.
