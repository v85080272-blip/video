# «Посёлок» — 3D-пилот для зрителей 20–40 лет

13.11 владелец попросил приключение в Blender, но «не для детей, а для аудитории 20–40 лет: у нас всё выглядит как
детский контент». Его идея: «зомби-апокалипсис, а ты застряла в коттеджном посёлке». Голос — «чуть сексуальный,
заигрывающий, и при неожиданном моменте вздох».

Рассказывает сама героиня, от первого лица, немного флиртуя со зрителем. Крови и смерти нет (правило с 12.11):
заражённые — просто «они», бледные, сутулые, в рваной одежде.

## Сюжет (45,5 с)

| План | Что видно | Голос |
|---|---|---|

| B | Внутри, за её спиной у окна: рука тянется к выключателю и опускается; за окном фонарь и улица | «Связи нет, шлагбаум закрыт. Свет я не включаю: они идут на свет.» |

Первые 3 кадра — обложка: «ЗАСТРЯЛА В ПОСЁЛКЕ? / НЕ ВКЛЮЧАЙ СВЕТ!» поверх первого кадра плана A.

## Как сделано

**Сцена** — `blender/posyolok.py`, Cycles на CPU, весь посёлок в одной сцене:
- асфальтовая улица;
- заборы из профнастила на кирпичных столбах, у каждого участка откатные ворота и калитка;
- двухэтажные коттеджи с сайдингом, двускатными крышами и окнами (в некоторых оставлен тёплый свет);
- натриевые фонари, один мигает;
- задние дворы: сетка-рабица, теплицы, сараи, сосны и берёзы;
- на въезде шлагбаум, будка охраны с холодным светодиодом, её белый кроссовер;
- лес вокруг, туман.

**Люди** — `blender/rig.py`. Это цельное гладкое тело, а не манекен из деталей:
- скелет из точек с радиусами;
- модификатор Skin, подразделение;
- меш раскрашен по зонам (куртка, джинсы, кожа, кроссовки) и привязан к арматуре автоматическими весами;
- колени и локти гнутся.

Героиня: 1,68 м, чёрная куртка, тёмные джинсы, белые кроссовки, длинный тёмный хвост.

Заражённые: выше и худее, сутулые, голова набок, неровная походка с подволакиванием, голова иногда дёргается.

**Героиня — Искра** (с 13–14.11). Владелец: «лицо всё равно страшное — срисуй с нашей девочки». Лепить лицо из
геометрии не вышло (манекен), поэтому так:
- на 3D-голову наложено её нарисованное лицо с листа персонажа (`blender/tex/iskra_neutral.png`, `iskra_smile.png`,
  вырезаны по глазам), проекция спереди;
- в финале, на «сделаю, как скажешь», лицо сменяется улыбкой (узел `smile` в материале);
- фиолетовое каре с бирюзовой прядью справа и жёлтой заколкой-молнией слева;
- оранжевая кожаная куртка с её молнией на спине (`blender/looks.py`: `iskra_mats`, `iskra_head`, `iskra_outfit`).

Остальная одежда: фактура кожи и денима, молния, ремень, карманы со строчкой, подошвы, пальцы (`dress_heroine`).
Сбоку и вблизи видно, что лицо нарисованное, — это цена такого способа.

**Голос** — ElevenLabs `eleven_v3`, голос Sweetie Fox из библиотеки («соблазнительный, завораживающий»). Модель v3
понимает метки в тексте: `[whispers]`, `[sighs]`, `[gasps]`, `[softly]`, `[laughs softly]`.
- Ударения проставлены знаком в поле `tts`.
- Озвучено два дубля (`tools/el_takes.py`), по каждой фразе взят дубль без ошибок ударения: L0 s1, L1 s1, L2 s2, L3 s1,
  L4 s2, L5 s2, L6 s2. У s1 в L2 вышло «шамашина», у s2 в L3 «заднИми».
- Она дышит медленно, вся роль шла около 60 с. Поэтому паузы длиннее 0,42 с внутри фраз сокращены до 0,26 с
  (`tools/tighten.py`, вздохи остаются), а темп поднят до 1,1 (тон не меняется). Итог — 45,5 с.

**Наложение** (`src/main.js`), по-взрослому сдержанное:
- белый узкий заголовок с тонкой красной чертой;
- печатающаяся метка времени «КП «СОСНОВЫЙ» · 02:47»;
- в плане C метки на карте из `build/screen.json` (Blender проецирует точки в кадр на первом и последнем кадре плана);
- кнопки выбора, вопрос зрителям, титры.

**Музыка** (`tools/music.py`): тихий ужас ре минор — гул, стеклянное тремоло, редкая челеста. Сердцебиение на выборе,
нарастание к вдоху, удар, когда загорается окно.

```bash
python3 tools/el_takes.py /home/user/work/posyolok 1 2
# дубли → cut_voice → pick_take; выбранные фразы → tools/tighten.py → снова в один дубль sF → cut_voice
cd tools && python3 voice.py ../voice/script.json ../build/voice.wav "*=/home/user/work/posyolok/c_sF" && cd ..
node render.mjs cues build/cues.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav && cd ..
EXPOSURE=1.6 python3 blender/shots.py build/cues.json /home/user/work/posyolok-r - 55 12      # около 20 с на кадр
cp /home/user/work/posyolok-r/f_C/screen.json build/screen.json
python3 tools/bg.py build/cues.json /home/user/work/posyolok-r build/bg.mp4
OVERLAY=1 FPS=30 node render.mjs video build/overlay.mov 1
# сборка: /home/user/work/posyolok-finish.sh (bg + наложение + звук, обложка, check_clip)
```

Пробный кадр одного плана: `TESTF=<кадр> EXPOSURE=1.6 python blender/posyolok.py A 7.4 <папка> 40 10 1`.

Статус: готово 13.11, с Искрой — 14.11; голос №1 (Sweetie Fox) — владелец выбрал его из трёх проб, третий голос (Мария Ляпина) тоже
понравился, его можно взять для второй серии или для второй версии пилота. `qa/check_clip.py`: ошибок нет, 45,5 с,
−14,0 LUFS, пик −2,1 dBTP, 46 слов из двух и более слогов с верным ударением. Замечания:
- пауза 2,5 с — вздох в первой фразе;
- пауза 1,9 с — окно выбора, так задумано.

Известное: в кадре сверху (план C) её дом ниже края кадра, поэтому метка «Я ЗДЕСЬ» не видна — пути выходят из-за
нижнего края.
