# «Лес горит» — «Зона», серия 5 (3D)

Под «Мёртвым городом» голосовали: ночь в Зоне или лесной пожар. Взяли пожар: по выгрузке YouTube Studio от 10.11
тёмные ночные начала теряют зрителей (51–62 % «продолжили смотреть»), а светлый первый кадр держит около 72 %.
С нами снова охотник, Пурга, гид и четверо из комментариев: Богдан, Коля, Настя и Мэри.

Серия сделана по правилам выгрузки Studio:
- первый кадр с 0 с светлый: горящий лес днём, «ЛЕС ГОРИТ?» и «НЕ БЕГИ ПО ВЕТРУ!»;
- без отсылок к прошлым сериям, 41,5 с;
- в середине СТОП: «1 проскочить сквозь дым» или «2 ткань на нос и пригнуться», полоска «ДУМАЙ»;
- в конце реальный случай (апрель 2020-го);
- голосование и «возьми с собой».

Радиационный контроль показан как настоящий пропускной пункт, а не рамка в поле (замечание от 10.11): дорога, будка,
шлагбаум, навес, дежурный с щупом. Голос говорит «пропускной пункт», а не «КПП», чтобы его не читали по буквам.

Сюжет и правила:
- по ветру огонь идёт быстрее всего, поэтому уходить поперёк ветра — к дороге или к реке;
- дым в Зоне несёт радиоактивную пыль из горящей подстилки;
- в дыму закрыть нос мокрой тканью и пригнуться, у земли воздух чище;
- у дороги пропускной пункт, всех проверяют и только потом выпускают.

Реальный случай: в апреле 2020-го огонь подошёл к станции примерно на 2 км, а дым дошёл до Киева. Источники
(МЧС, NOAA, SciJinks, Atlantic Council, AP) — в `voice/script.json` (`note`).

Планы (`blender/fire.py`, всё в одной сцене):
- A — поляна, стена огня за ними;
- B — поворачивают на восток, поперёк ветра;
- C — охотник крупно, светящаяся пыль в дыму, дозиметр;
- D — стена дыма накрывает дорогу;
- E — шарфы на нос, пригнувшись, вдоль дороги;
- F — пропускной пункт, щуп над охотником;
- G — 2020: издалека арка над реактором, перед ней горит лес и встают столбы дыма;
- H — за шлагбаумом, оборачиваются и машут.

Дым сделан плоскостями с мягкой круглой маской, повёрнутыми к камере: объёмный дым считался 158 с на кадр.
Огонь — излучающий материал с 4D-шумом во времени. Каждый план рендерится через `marks.step` кадров
(`src/main.js`, `STEP`), `tools/bg.py` дорисовывает промежуточные (minterpolate).

```bash
python3 blender/shots.py build/cues.json /home/user/work/zone-fire-r - 50 8
python3 tools/bg.py build/cues.json /home/user/work/zone-fire-r build/bg.mp4
OVERLAY=1 FPS=30 node render.mjs video build/overlay.mov 1
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav && cd ..
ffmpeg -i build/bg.mp4 -i build/overlay.mov -i build/mix.wav -filter_complex "[0:v]tpad=stop_mode=clone:stop=4[b];[b][1:v]overlay=format=auto,format=yuv420p[v];[2:a]afade=t=out:st=41.02:d=0.5[a]" -map "[v]" -map "[a]" -c:v libx264 -preset slow -crf 16 -c:a aac -b:a 256k -ar 48000 -shortest -movflags +faststart out/zona-les-gorit.mp4
```

Голос: L0 s4, L1 s1, L2 s4, L3 s5, L4 s3, L5 s5, L6 s3, L7 s3 (`qa/pick_take.py --asr`, ударения без ошибок).
Микс −14,2 LUFS, пик −2,2 dBTP.

Статус: рендер идёт.
