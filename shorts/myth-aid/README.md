# «Правда или миф» №8 «Первая помощь» — Искра голосом из ElevenLabs

Это проверка голоса. В №7 Искра говорила синтетическим голосом №2 (`shorts/iskra-voice`). Здесь голос Elen Kuragina
из библиотеки ElevenLabs: «персонажи и анимация, эмоциональный», его выбрал владелец 11.11. Ведущие, формат,
обложка и длина те же, поэтому по досмотру и комментариям к №7 и №8 видно, какой голос заходит лучше. В закрепе №8
прямо спрашиваем: «Какой голос Искры нравится больше?»

## Голос через ElevenLabs
Скрипт `tools/el_takes.py` читает каждую фразу через API и собирает их в один дубль того же вида, что делает
`voice/takes.sh`, так что дальше работает обычная цепочка: `cut_voice.py`, затем `pick_take.py --asr`.
- Ключ API в коде не хранится: прокси сессии сам подставляет его в запросы к api.elevenlabs.io.
- Модель `eleven_multilingual_v2`, скорость 1,08. Каждой фразе передаётся соседний текст (`previous_text` /
  `next_text`), чтобы интонация шла связно.
- Голос сначала нужно добавить к себе, это бесплатно: `POST /v1/voices/add/{owner}/{voice_id}`. У Elen это сделано,
  `voice_id` — `TPIitICAZ8CqlGZ81AKm`.
- Ударение в имени и в трудных словах ставится знаком ударения U+0301 в поле `tts`: «И́скра», «зажми́», «звони́»,
  «уложи́»… Без знака ElevenLabs читала «искрА». С ним все восемь фраз прошли проверку с первого дубля, перегенерация не
  понадобилась. Субтитры берутся из `text`, без знаков.
- Затраты: один дубль — 567 символов, около 230 кредитов; всего с пробами голосов потрачено 300 из 40 000 в месяц.
- Elen читает неторопливо, поэтому поверх скорости 1,08 дан темп 1,1 (`"tempo"`, тон не меняется) и паузы чуть короче:
  46,9 с вместо 51,3.

```bash
python3 tools/el_takes.py /home/user/work/myth-aid 1        # дубль s1 (ONLY="L2 L5" — только эти фразы)
cd /home/user/work/myth-aid && python3 -I /home/user/video/shorts/zombie-panelka/tools/cut_voice.py takes/s1.wav script.json c_s1
cd /home/user/video/shorts/myth-aid/tools && python3 voice.py ../voice/script.json ../build/voice.wav "*=/home/user/work/myth-aid/c_s1"
cd .. && node render.mjs cues build/cues.json && python3 tools/mouth.py build/voice.wav build/mouth.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav && cd ..
node render.mjs video build/video.mp4 3
```

## Советы и факты
1. «Пошла кровь из носа — запрокинь голову» — **миф**. Кровь стечёт в горло. Нужно наклониться вперёд и зажать мягкую
   часть носа на 10–15 минут (NHS; healthdirect).
2. «Обжёгся — намажь маслом» — **миф**. Масло держит жар в коже. Нужно держать под прохладной проточной водой 20 минут
   (NHS «Burns and scalds»; Британский Красный Крест).
3. «Обморок — уложи и подними ноги» — **правда**. Кровь вернётся к голове. Если человек не пришёл в себя за минуту —
   звонить 112 (NHS «Fainting»).

Сцены в `src/aid.js`:
1. Голова в профиль: запрокидывается, и кровь пунктиром течёт в горло; потом наклон вперёд, рука зажимает нос, «10 МИН».
2. Рука с ожогом: на неё льётся масло, поднимается жар; потом кран, вода и «20 МИН».
3. Человек на коврике: ноги поднимаются на табуретку, стрелки показывают, как кровь идёт к голове; «1 МИН» и телефон 112.

Ведущие, речь Искры и обложка — как в №7 (`myth-forest/README.md`).
