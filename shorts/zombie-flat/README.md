# Зомби в панельке · «Правило №6» (плоская 2D)

Вертикальный мультик 1080×1920, 60 к/с, 22,5 с, без закадрового голоса. Первая проба скилла vizavi_motion по брифу vla от 19.10.2026: «2D: плоские формы, ясные силуэты и движение в плоскости кадра, простая читаемая композиция». Кот Батон стережёт дверь на 9-м этаже, зомби поднимается к нему из темноты, а кот распушается так, что его тень накрывает тень зомби. Зомби теряет руку, убегает на 8-й этаж и прячется в чужой квартире. Вывод — «Правило №6: заведи кота». Конец переходит в начало (кот снова лижет лапу), так что ролик крутится по кругу.

Каждый кадр рисует код (Node + `@napi-rs/canvas`), музыка и звуки синтезированы в numpy, сторонней музыки и сэмплов нет. Раскадровка с вариантами каждой сцены — `STORYBOARD.md`.

## Картинка

- `src/flat.js` — плоские формы: сглаженные контуры, шипы шерсти, трубки-конечности, IK для ног, кадры координат с отражением; режим `MONO` рисует персонажа одним цветом для тени на стене.
- `src/set.js` — подъезд в разрезе: площадка 9-го этажа с дверью 36, пролёт, площадка с окном (улица и луна в дальнем слое 0,5), второй пролёт, 8-й этаж с дверью 32, труба в ближнем слое 1,35.
- `src/cat.js`, `src/zombie.js` — Батон (от сидячей позы до выгнутой спины, шерсть дыбом, лизание, шипение, хвост, моргание) и зомби (ноги по точкам стоп, руки, челюсть, глаза, слюна).
- `src/type.js` — надписи с плоской тенью, штамп, кнопка.
- `src/main.js` — весь ролик как функции времени: шаги на доли 120 BPM, игра персонажей, камера по ключам (сплайн) с пружиной на ударе, тени на стене (персонаж одним цветом, растянут и наклонён от стоп), буквы, склейка и точки, через которые смаз не переходит (`CUTS`), звуковые метки `cues()`.
- `render.mjs` — смаз движения: на быстрых кадрах до 16 подкадров внутри затвора 180°, сколько нужно по сдвигу на экране; затвор не перескакивает склейку и мгновенный разворот.

## Звук

- `tools/sfx.py` — эффекты из серии 1 (шипение, хлопок двери, стоны, свисты), `tools/fx.py` — новые: шаги и бег, принюхивание, капля, стук хвоста, отлетевшая рука и её отскоки, скрип двери, сдувание, штамп, лизь, мурчание и другие.
- `tools/music.py` — партитура по разделам, у каждого своя громкость во времени: тише в начале подъёма, громче к нависанию, мёртвая тишина 10–11 с, удар, погоня, разрядка. Хвост реверберации после 22,5 с переносится в начало, чтобы круг замыкался без шва.
- `tools/mix.py` — голоса нет, поэтому опора — музыка: самые громкие 400 мс каждого эффекта не громче музыки вокруг него (−1 LU; там, где музыка тихая или молчит, — не громче её общей громкости −7 LU), тихие текстуры на 5 LU ниже, и только шипение кота может быть громче музыки на 4 LU. Под всем тихий гул подъезда, закольцованный кроссфейдом. −14 LUFS, true peak до AAC −2,2 dBTP, после AAC −1,9. Замеры по каждому эффекту — `build/mix_levels.json`.
- `tools/report.py` — график громкости музыки и микса с метками и спектрограмма: проверка без прослушивания.

## Сборка

```bash
npm install
python3 -m pip install numpy scipy soundfile matplotlib
node render.mjs stills tmp/st 2.8 11.4 18.6        # проверочные кадры
node render.mjs cues build/cues.json               # звуковые метки и тайминги
python3 tools/music.py build/cues.json build/music.wav
python3 tools/mix.py build/cues.json build/music.wav build/mix.wav
python3 tools/report.py build/cues.json build/music.wav build/mix.wav
node render.mjs video build/picture.mp4 4          # 1350 кадров в 4 потока, около 1,5 мин
ffmpeg -i build/picture.mp4 -i build/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -ar 48000 -movflags +faststart build/pravilo6.mp4
```

## Проверено

Готовый файл декодирован заново: H.264 1080×1920, 60 к/с, yuv420p, 1350 кадров, AAC 48 кГц стерео, 22,5 с; звук совпадает с миксом без сдвига; −14,3 LUFS, true peak −1,9 dBTP. Покадровая разница даёт скачки только там, где они задуманы (удар на 11,0, склейка на 16,0, разлёт текста на 19,6), первый и последний кадры почти совпадают. Звук измерен и разобран по графикам, но не прослушан человеком.
