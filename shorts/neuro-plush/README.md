# Ты думаешь или зависла?

3D-мультик (1080×1920, ~91 с) по сценарию vla: котёнок Плюш и робот Нейро на диване в дождливый вечер.
Тема: зачем нейросети уровень рассуждения. Плюш просит путь к батарее, Нейро сравнивает маршруты на максимуме,
а кот тем временем греется у неё на коленях: «Батарея была гипотезой».

Сборка:
```
python3 tts.py                  # голоса RHVoice (apt: rhvoice rhvoice-russian) → out/tts_*.wav, огибающие в story.json
python3 tts.py --neural DIR     # или готовые файлы DIR/<id>.wav (например, нейроголоса VoxCPM2)
python3 layout.py               # тайминги реплик и кадров по длине голосов
node render.mjs --shot 4,15,45 --dir out/stills          # пробные кадры
node render.mjs --from 0 --to 23 --out out/p1.mp4        # куски видео (можно параллельно)
python3 mix.py                  # музыка, дождь, мурчание, звуки, голоса → out/mix.wav
```
Модули: `core.js` (рендерер, помощники), `lights.js` (свет гостиной), `room.js` (гостиная, окно с дождём, батарея,
коробки, пылесос), `plush.js` (котёнок с шерстью из оболочек), `neuro.js` (робот), `holo.js` (голограммы: ползунок,
карта маршрутов, «Операция Батарея»), `ui.js` (субтитры, текст, цветокор), `main.js` (таймлайн, позы, камера).
Контракт персонажей: `CONTRACT.md`; проверочные страницы `test-*.js` открываются через `test.html?mod=...`.
