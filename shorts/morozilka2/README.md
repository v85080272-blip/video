# Морозилка, серия 2 «Новенький»

Рука подкидывает в морозилку бодрого Блинчика: «Привет! Я тут ненадолго!». Пельмень Петрович: «Все так говорят.» Неловкая пауза, крышка, Блинчика забирают («Ой! Уже?»). Сырник: «Он был прав.» Финал: «Кто следующий? Голосуй в комментах».

Сборка такая же, как у серии 1 (см. `shorts/morozilka/README.md`): папку кладут в `films/` движка lemo-opuscar, `story.json` задаёт время и для картинки, и для `mix.py`. Эмодзи-шрифт `NotoColorEmoji.ttf` копируется в `fonts/` из системы.
