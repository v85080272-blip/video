## Что нового по сравнению с №1

- **Машина** (`car()` в `blender/posyolok.py`): кузов кроссовера, стёкла с прозрачностью, водительская дверь на петле
  (`CARL['hinge']`), сиденья, руль, приборная панель, фары, задние фонари и приборы с ключами анимации (`ignite(f)`),
  лучи фар в тумане. Перед машины — к −y, место водителя — по локальной +x.
- **Ключи в руке** (`keys_in_hand`), поза на сиденье (`seat_pose`), заражённый у окна (`GATE_INF`).
- **Звук мотора** (`tools/fx.py`: `engine()`), щелчок замка, скрип двери, удар в окно.
- **Музыка** (`tools/music.py`): тот же тихий ужас ре минор; сердцебиение на выборе, рёв мотора на зажигании, удар
  на стуке в окно.
- Кадры фона пишутся с crf 16 (в №1 — 10), чтобы хватило диска.

## Голос

ElevenLabs `eleven_v3`, Sweetie Fox, как в №1. Метки `[whispers]`, `[sighs]`, `[gasps]`; ударения — знаком в `tts`
(омографы: замке́ / замка́, тара́ню). Два дубля, по каждой фразе взят дубль без ошибок ударения:
L0 s2, L1 s2, L2 s1, L3 s1, L4 s2 (у s1 «зАкрыт» под музыкой), L5 s1, L6 s2 (у s1 «таранЮ»).
Роль шла 49,6 с: паузы внутри фраз сокращены (`tools/tighten.py`, 0,32 → 0,2 с), темп 1,14. Расход — около 1 100
кредитов.

```bash
python3 tools/el_takes.py /home/user/work/posyolok2 1 2
# дубли → cut_voice → pick_take (--text без знаков ударения); выбранные фразы → tools/tighten.py 0.32 0.2 → один дубль sF → cut_voice
cd tools && python3 voice.py ../voice/script.json ../build/voice.wav "*=/home/user/work/posyolok2/c_sF" && cd ..
node render.mjs cues build/cues.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav && cd ..
EXPOSURE=1.6 python3 blender/shots.py build/cues.json /home/user/work/posyolok2-r - 55 12
python3 tools/bg.py build/cues.json /home/user/work/posyolok2-r build/bg.mp4
OVERLAY=1 FPS=30 node render.mjs video build/overlay.mov 1
# сборка: /home/user/work/posyolok2-finish.sh (фон + наложение + звук, обложка, check_clip)
```

Пробный кадр: `TESTF=<кадр> EXPOSURE=1.6 python blender/posyolok.py E 4.9 <папка> 40 10 1`.

Статус: готово 15.11. `qa/check_clip.py`: ошибок нет, 45,2 с, −14,0 LUFS, пик −2,1 dBTP, 46 слов из двух и более
слогов с верным ударением. Замечание — пауза 1,8 с на 15,5 с: окно выбора, так задумано.

После сборки поправлено наложение (без перерендера 3D):
- кнопки выбора расширяются под подпись: «НАЖАТЬ НА БРЕЛОК» и «ТАРАНЮ ШЛАГБАУМ» вылезали за край;
- заголовок обложки уменьшен со 104 до 92 пт: «ДО МАШИНЫ 20 МЕТРОВ» упирался в края кадра.

Пересборка только наложения и звука: `/home/user/work/posyolok2-remux.sh`.

Известное:
- план E (из салона) тёмный, приборную панель почти не видно;
- в плане F рука того, кто бьёт в окно, крупная и размытая — читается как тень у окна.
