## Как сделано

**Ведущие** — спрайты, вырезанные из листов. Фон листа — бумага светлого цвета, связанная с краем; дырки бумаги между
рукой и телом тоже вырезаются (`tools/cutout.py`, результат — `img/*.png`):
- Искра: шесть жестов `i_*`, восемь лиц `h_*`, четыре бюста `b_*`;
- котик: шесть поз `c_*`;
- экраны рюкзака: `d_*` (✓, ✗, ?).

В кадре Искра стоит слева по пояс (720 px, увеличение 1,75×), котик справа. Оба чуть дышат; при смене позы Искра
«подпрыгивает», котик подпрыгивает при смене реакции.

**Речь Искры.** Рот закрашен цветом кожи, поверх нарисованы закрытые губы (`img/i_*_closed.png`). Открытый рот из листа
(`img/i_*_mouth.png`) рисуется поверх и сжимается по громкости голоса:
- `tools/mouth.py` → `build/mouth.json`, 60 кадров/с;
- рты размечены вручную по сетке 4× в `tools/prep_sprites.py`: цветовой поиск путал рот с серёжкой;
- пока голос молчит, у Искры её собственная улыбка из листа;
- в позе «миф» (скрещённые руки) рот не двигается.

**Голос Искры — синтетический.** Он создан Qwen3-TTS VoiceDesign по описанию «female, young adult, warm and soft,
medium pitch, lively, friendly, smiling». Это ничей реальный голос. Были ещё два варианта, «яркий» и «пониже»; все три
лежат в `/home/user/work/iskra-voice`. Образец (`refB`) служит опорой для базовой модели, поэтому во всех дублях один и
тот же голос.

**Сцены** нарисованы без людей (`src/forest.js`), ведущие стоят перед ними. Три колонки, как в №6:
1. Ствол со мхом и компас. На ответе мох появляется со всех сторон, а пунктир «ходишь кругами».
2. Куст ягод и клюющая птица. На ответе на ягодах черепки.
3. Поляна и «ТЫ ЗДЕСЬ». На ответе телефон 112, «АУ!» и три пунктира спасателей сходятся к метке.

## Советы и факты
1. «Север легко найти по мху» — **миф**. Мох растёт там, где сыро и тень, это бывает с любой стороны: будешь ходить
   кругами (Woodland Trust; Forest Preserve District of Will County).
2. «Ягоды, которые клюют птицы, можно есть и тебе» — **миф**. Птицы едят ягоды, ядовитые для человека: лаконос,
   падуб, девичий виноград (BirdNote).
3. «Заблудился — остановись и оставайся на месте» — **правда**. Так тебя скорее найдут: звони 112 и подавай голос
   (советы «ЛизаАлерт»).

```bash
python3 tools/prep_sprites.py                        # рты: закрытые позы и открытые рты
node render.mjs cues build/cues.json
python3 tools/mouth.py build/voice.wav build/mouth.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav && cd ..
node render.mjs video build/video.mp4 3
```
