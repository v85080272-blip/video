# «Загорелась проводка, ты дома» (плоская 2D, «Как выжить»)

Вертикальный мультик 1080×1920, 60 к/с. Дальняя комната, охотник и лайка Пурга из «Дыма в подъезде», рассказчик
канала.

Почему сделан (20.11): «Облако хлора» («ты» дома, вопрос с первого кадра) — лучший из новых. Владелец: «делай и го
выкладывать больше роликов», потом «в течение дня дропать каждый час». Без ведущей и без номера серии.

## Сюжет и факты

| Шаг | Что видно | Голос |
|---|---|---|
| Вопрос (0 с) | Обложка: горит розетка, «ЗАГОРЕЛАСЬ РОЗЕТКА? / НЕ ЛЕЙ ВОДУ!». Розетка у дивана, в ней вилка масляного обогревателя; на «заискрила» — искры, на «загорелся» — пламя по шнуру; по словам: «ЧТО ДЕЛАТЬ, / ЕСЛИ РОЗЕТКА ЗАИСКРИЛА / И ЗАГОРЕЛСЯ ШНУР?» | «Что делать, если розетка заискрила — и загорелся шнур?» |
| Первая мысль | Он со стаканом воды; на «Нельзя» — красный крест, «ВОДА ПРОВОДИТ ТОК / провод под напряжением» | «Первая мысль — плеснуть водой. Нельзя: провод под током, а вода проводит ток.» |
| 1 | Он выдёргивает вилку; карточка «ЩИТОК»: четыре автомата опускаются, «ТОКА НЕТ» | «Первое: выдерни вилку из розетки или выключи автоматы в щитке.» |
| 2 | Набрасывает шерстяное одеяло, огонь гаснет; «НЕ СИНТЕТИКОЙ / плотная ткань: шерсть, хлопок» | «Второе: огонь маленький? Накрой его плотной тканью — не синтетикой.» |
| 3 | Огонь сильнее («НЕ ГАСНЕТ?»), он выходит и закрывает дверь; телефон набирает 101 | «Третье: не гаснет? Уходи, закрой за собой дверь и звони сто один.» |
| Секрет | Маленький щиток «ТОКА НЕТ» с галочкой; он выливает стакан на шнур — пар, огонь гаснет; «ТОК ВЫКЛЮЧЕН — МОЖНО ВОДОЙ» | «А секрет такой: когда ток выключен, тушить водой уже можно.» |
| Конец | С огнетушителем, большой палец вверх; «ЕСТЬ ДОМА ОГНЕТУШИТЕЛЬ? / пиши в комментариях»; «ПОДПИСЫВАЙСЯ» | «А у тебя дома есть огнетушитель? Пиши! И подписывайся!» |

Факты — материалы региональных управлений МЧС об электроприборах и пожаре в квартире:
- загорелся прибор или шнур — выдернуть вилку или обесточить квартиру в щитке;
- не тушить водой, пока прибор под напряжением;
- небольшой очаг на начальной стадии тушат подручными средствами: накрыть плотной тканью (не синтетикой) или
  огнетушителем;
- не получается — уйти, закрыть за собой дверь, звонить 101 или 112;
- когда ток выключен, водой тушить можно.

Без крови и смерти.

## Как сделано

Основа — `../smoke-stairs`.
- **`src/elec.js`** (новое):
  - розетка с вилкой масляного обогревателя, шнур по полу;
  - искры, пламя по шнуру, следы копоти;
  - шерстяное одеяло, вода из стакана и пар;
  - огнетушитель;
  - карточка «ЩИТОК» с четырьмя автоматами.
- **`src/main.js`**:
  - весь ролик в дальней комнате, семь планов по словам рассказчика;
  - вопрос-заголовок по словам; обложка в первых 3 кадрах.

## Голос

Рассказчик канала (Qwen3-TTS Base), четыре дубля: `/home/user/work/socket`. ElevenLabs не тратился.

Взяты фразы:
- L0 — было «…и загорелся провод?»: в трёх дублях «провОд», в четвёртом «зАискрила». Переписано «…загорелся шнур?» и
  перечитано (`/home/user/work/socket-b`), взят s3;
- L1 — s3 (в s2 и s4 «провОд»);
- L2 — s2;
- L3 — s3;
- L4 — s4;
- L5 — s3;
- L6 — s2.

```bash
PAR=2 bash voice/takes.sh 1 2 3 4
ONLY="L0" OUT=/home/user/work/socket-b PAR=2 bash voice/takes.sh 1 2 3 4
WD=socket EPS=socket-fire bash /home/user/work/myth-pick.sh
WD=socket-b EPS=socket-fire ONLY="L0" bash /home/user/work/myth-pick.sh
cd tools && W=/home/user/work/socket && python3 voice.py ../voice/script.json ../build/voice.wav L0=/home/user/work/socket-b/c_s3 L1=$W/c_s3 L2=$W/c_s2 L3=$W/c_s3 L4=$W/c_s4 L5=$W/c_s3 L6=$W/c_s2 && cd ..
bash /home/user/work/socket-build.sh     # cues, музыка, сведение, видео, обложка, check_clip
```
