# «Грибок из реактора» (серия «Жизнь в Чернобыле», история с картинками)

Вертикальный ролик 1080×1920, 60 к/с, ≈39 с. Восемь фотореалистичных кадров нарисовал Codex на компьютере владельца
(`CODEX.md`), увеличены Real-ESRGAN до 2160×3840 (`img/01–08.jpg`). Голос — рассказчик из ElevenLabs (Amid Hasan),
субтитры-караоке, плашки, обложка-приманка (первый кадр и превью), пометка «ИИ-реконструкция» на каждом кадре. Без «а ты
бы…» и без «Стоп» (владелец, 22.11). Серию придумали владелец с GPT: «необычный первый кадр, пугающий вопрос и
неожиданный ответ».

## История и факты

| Кадр | Голос |
|---|---|
| 01 чёрная плесень (обложка «ГРИБОК ЛЮБИТ РАДИАЦИЮ?!») | «Внутри разрушенного реактора в Чернобыле, где человеку находиться нельзя, на стенах растёт чёрная плесень.» |
| 02 разрушенный зал | «Радиация там огромная. А грибок живёт и разрастается.» |
| 03 проба со стены | «Учёные из Нью-Йорка решили проверить такие грибы в лаборатории.» |
| 04 микроскоп | «У этих грибов есть тёмный пигмент — меланин.» |
| 05 чашки с грибом | «Их облучили — в пятьсот раз сильнее обычного фона.» |
| 06 сравнение | «И грибы с меланином стали расти быстрее.» |
| 08 грибок в луче | «Учёные считают, что меланин помогает им использовать энергию излучения. Как именно — ещё изучают.» |
| 07 кожа | «А секрет такой: этот же пигмент есть и в твоей коже. Знал об этом? Пиши! И подписывайся!» |

Факты: Dadachova et al., PLoS ONE 2(5): e457, 2007 — меланизированные грибы колонизируют стены разрушенного реактора
(фон статьи); в лаборатории грибы с меланином под излучением примерно в 500 раз выше фона росли быстрее; облучение
меняло электронные свойства меланина. Не утверждаем, что грибы «питаются одной радиацией». Источники: plosone.org,
Nature news (2007).

## Как сделано

Таймлайн собран генератором серии из `../izhma-landing` (`scratchpad/gen/series.py`: кадры, плашки, обложка, звуки,
метки музыки). Голос: два дубля ElevenLabs (`tools/el_takes.py`, `/home/user/work/chernobyl-fungus-el`), паузы ужаты и
речь ускорена на 12 % (`/home/user/work/tighten.py`).
