# «Свет дали» (плоская 2D, блэкаут ч.7)

Вертикальный мультик 1080×1920, 60 к/с, около 45 с, серия «Как выжить», мини-сезон «Блэкаут» (план — `../BLACKOUT-SEASON.md`).
Продолжает ч.6. Тот же охотник, лайка Пурга с фонариком, рассказчик серии.

## Сюжет

Пятый день, свет дали, возвращение домой на 20-й этаж: технику включать по одной, воду открывать понемногу и смотреть трубы, оттаявшее из морозилки выбросить. Поворот: дома снова +20, лёд в ванне из ч.1 растаял, Пурга спит у батареи.

Текст и источники фактов — `voice/script.json`. Голос — `voice/takes.sh` (поле `tts`: «пурга» со строчной, чтобы голос сказал «пургА»).
Сборка — как в `../blackout-week/README.md`.

Статус: сценарий готов, идёт озвучка и картинка.
