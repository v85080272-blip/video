## Что нового в 3D (`blender/posyolok.py`)

- **Новая Искра** — модель TRELLIS.2 по листам персонажа с риггингом (`blender/iskra3d/iskra_rigged.blend`,
  `heroine_new()`); старая — `ISKRA=old`.
- **Фото-текстуры** Poly Haven (CC0) — рендер с `PBR=1` (см. «Фото-текстуры» ниже).
- **Машина едет:** `drive([(кадр, y)])` двигает машину, `ride(...)` привязывает к ней героиню, камеру и того, кто
  висит на двери (`hanger()`); героиня сидит в машине через `seat_local()`.
- **Шлагбаум ломается:** `break_barrier(кадр)` — два крайних куска палки отлетают и кувыркаются, остальная палка
  дёргается.
- **Ремень и замок** (план B): лента ремня вытягивается от стойки, пряжка, кнопка замка уходит вниз.
- **Лесная дорога:** асфальт 248 м с разметкой, 110 сосен и берёз; туман на каждом плане свой (не слепит фары).
- **Тот, кто машет** (план F): стоит на обочине в 13 м перед машиной, машет рукой.
- **Метки поверх кадра:** план C пишет `screen.json` (где на экране столб и конец палки), наложение рисует по нему
  крест и стрелку.
- Старые планы №2 переименованы в `X2A`…`X2G`.

## Голос

ElevenLabs `eleven_v3`, Sweetie Fox, как в №1–2. Метки `[whispers]`, `[sighs]`, `[gasps]`, `[softly]`,
`[laughs softly]`; ударения — знаком в `tts` (омографы: на замо́к, на двери́). Два дубля, по каждой фразе взят дубль
без ошибок ударения: L0 s1, L1 s1, L2 s1, L3 s2, L4 s3, L5 s2 (у s1 «двЕри»), L6 s2, L7 s1.
Фраза L4 была «Удар! Палка улетела…» — в обоих дублях «палкА»; переписана на «Удар! Её снесло…» и перечитана
(`/home/user/work/posyolok3-b`). Роль шла 56,7 с: паузы внутри фраз сокращены (`tools/tighten.py`, 0,3 → 0,18 с),
темп 1,18 — 40,8 с. Расход — около 1 200 кредитов.

```bash
python3 tools/el_takes.py /home/user/work/posyolok3 1 2
# дубли → cut_voice → pick_take; выбранные фразы → tools/tighten.py 0.3 0.18 → один дубль sF → cut_voice
cd tools && python3 voice.py ../voice/script.json ../build/voice.wav "*=/home/user/work/posyolok3/c_sF" && cd ..
node render.mjs cues build/cues.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav && cd ..
# 3D: /home/user/work/posyolok3-render.sh (PBR=1 EXPOSURE=1.6, 55 %, 12 сэмплов)
# сборка: /home/user/work/posyolok3-finish.sh (фон, наложение, звук, обложка, check_clip)
```

Пробный кадр: `PBR=1 EV="0.02,0.377" TESTF=330 EXPOSURE=1.6 python blender/posyolok.py F 12.24 <папка> 35 10 1`
(`EV` — доли плана, где стоят события; берутся из `build/cues.json`).
