# Голос v3: как у диктора из референсов vla

15.10.2026 vla прислал два рилса из серии-образца файлами (разбор в `../reference_reels.md`) и попросил голос как у
того диктора. Делаем похожий типаж, а не копию: голос создаётся по описанию (Qwen3-TTS VoiceDesign), с оригиналом
сравниваются только замеры.

1. `voice_profile.py <видео или wav> <папка> [имя]` — профиль голоса: высота тона, темп (Whisper кусками по 8 с, иначе
   он пропускает фразы), паузы, наклон спектра и эмбеддинг диктора Qwen3-TTS (`qwen-codec --talker` → `.spk`, 2048 чисел).
2. `run_cast.sh` — 12 голосов по описаниям из `variants.json` читают `sample.txt`.
3. `cast_score.py` — сходство тембра с оригиналом (косинус эмбеддингов после вычитания среднего по набору голосов:
   один и тот же диктор в двух рилсах даёт 0,69, разные голоса от −0,5 до 0,4), разница высоты в полутонах, темп,
   UTMOS. Результаты в `cast_scores.json`. Ближе всех вышел старый `v1_deep` из первого кастинга (0,39), из новых
   `c4_s31` (0,27) и `c3_s33`.
4. `make_page2.py` — страница «Голос для «Тайн истории»» (версия 2): кусок оригинала, три финалиста на одном тексте,
   нынешний голос для сравнения.
5. `revoice.py <id> <wav образца> <текст образца>` — клон выбранного голоса и переозвучка обоих выпусков: 3 дубля на
   фразу, CER и UTMOS, ещё 3 дубля для фраз без чистого дубля, выбор, экспорт −20 dBFS, манифест слов для субтитров.

Ударения: Qwen3-TTS не понимает пометок в тексте. «+» перед гласной читается как «плюс», знак ударения (U+0301)
превращается в лишний звук «й/ю» («заюмок»), заглавная буква не ломает слово, но и ударение надёжно не сдвигает
(`stress_gen.py`, `stress_measure.py`). Неверное ударение лечится другим дублем или другой формулировкой.
