20.10.2026 vla прислал пробу MiniMax «Engaging Historian» (скорость 0,9, файл D-historian-calm.mp3, 11,7 с):
«этот мне очень нравится голос». В API MiniMax этого голоса нет (только в библиотеке сайта), а бесплатные кредиты
сайта кончились. Копию голоса не делаем: он принадлежит MiniMax, а за ним, скорее всего, живой диктор. Образец
служит только для замеров и сравнения на слух; голоса подбираем по описанию, как в раундах 2–3 (`../voice3`, `../voice4`).
Сам образец в репозиторий не кладём.

## Как подбирали

1. `variants.json`: 5 описаний («низкий тёплый рассказчик-историк» в разных вариантах) × seed 51–53, все читают текст
   образца (`sample.txt`). `run_cast.sh` и `run_cast_rev.sh` — два воркера навстречу друг другу (около 75 с на пробу
   вместо 110 с у одного).
2. `cast_score6.py` (это `../voice4/tools/cast_score3.py` с целями образца): сходство тембра по эмбеддингу Qwen3-TTS
   (за вычетом среднего), высота, разброс тона, темп, UTMOS. Итог в `cast_scores.json`. Сходство тембра у всех слабое
   (лучшее 0,15; в раунде 3 было 0,39): похожая манера получается, похожий тембр нет.
3. Финалисты: `h4_s52` «Историк» (самый живой разброс тона, 13,2 полутона на кастинге), `h2_s53` «Ночной» (ближе всех
   по высоте и тембру, но интонация ровная), `h3_s51` «Глубокий» (самый естественный по UTMOS). Клон каждого (Base, ICL)
   читает весь сценарий №7 одним запросом: `../voice5/tools/gen_cont.py <id> ../okene2013/script.json <папка> 1`
   (референсы лежат в `/home/user/work/voice3/ref/<id>.*`, около 4–7 минут на дубль).
4. Ударения: `python3 /mnt/project-files/qa/pick_take.py --asr --text ../okene2013/script.json <дубли>`.
   Замеры дублей для страницы: `measure_reads.py`.
