# «Взрыв на станции, ты дома» (плоская 2D)

Вертикальный мультик 1080×1920, 60 к/с, около 43 с, серия «Как выжить». Бриф vla от 27.10.2026: «давай ещё про радиацию, но ты в доме, и взорвался завод: твои действия», в той же графике, с тем же рассказчиком и субтитрами, что «Радиоактивное озеро». Ролик начинается с вопроса «Что делать, если рядом взорвалась атомная станция, а ты дома?». Охотник пьёт чай у окна, за окном вспыхивает станция. Первая мысль — выйти и снять на телефон — перечёркнута: ветер несёт радиоактивную пыль. Дальше пять шагов: закрыть окна, двери, печную заслонку и выключить вентиляцию; спуститься в погреб (каждая стена ослабляет излучение); пить воду только из бутылок, есть из банок и холодильника; не пить йод самому (таблетки только по сигналу по радио, и они защищают лишь щитовидку); включить радио и ждать минимум сутки. Конец — призыв подписаться и отъезд камеры: вся изба в разрезе и дым над крышей.

Каждый кадр рисует код (Node + `@napi-rs/canvas`), музыка и звуки синтезированы в numpy, сторонней музыки и сэмплов нет. Раскадровка с вариантами сцен, источниками фактов и тем, что исправлено после первой сборки, — `STORYBOARD.md`.

## Картинка

- `src/flat.js`, `src/lib.js`, `src/camera.js` — плоские формы, сглаживание, IK, камера со слоями глубины.
- `src/house.js` — изба в разрезе: стена с окном (наличник, створки), русская печь с заслонкой, вентилятор с выключателем, дверь с засовом, стол с календарём, пол с люком, погреб (полки банок, бутылки воды, ящик, табурет, лампа, лестница), реквизит (чашка, телефон, аптечка, йод, радио); даль со станцией (градирни, реактор, полосатая труба, ЛЭП) и взрыв (огненный шар, столб дыма с шапкой, ударная волна); фасад избы снаружи; пыль и ветер.
- `src/world.js` — небо и знак радиации из «Радиоактивного озера» (остальное там для прошлого ролика).
- `src/hunter.js` — охотник: ушанка, борода, тельняшка, дозиметр на груди.
- `src/overlay.js` — шкала «ДОЗА», кресты, галочки, номерные плашки, карточки: стены против лучей, кран, холодильник, «ЙОДИД КАЛИЯ / ПО СИГНАЛУ», щитовидка, часы «24 ЧАСА», финальные плашки.
- `src/type.js` — надписи и субтитры по словам (опасное красным, что делать — зелёным).
- `src/main.js` — весь ролик как функции времени: моменты привязаны к словам рассказчика (`build/words.json`), планы камеры, позы героя, шаги по точкам стоп, звуковые метки `cues()`.
- `render.mjs` — кадры для просмотра или видео с размытием движения (затвор не переходит склейку).

## Голос

Текст — `voice/script.json`. Голос — рассказчик «Зомби в панельке» (свой синтетический голос, Qwen3-TTS Base, `voice/takes.sh`, по дублю на зерно). Чужие голоса не клонируются. `../zombie-panelka/tools/cut_voice.py` режет дубль на фразы по словам Whisper. Ударения проверяет общая проверка (`qa/pick_take.py`), лучший дубль каждой фразы ставит `tools/voice.py` в `build/voice.wav` и `build/words.json`. В ролике (27.10): L0 из дубля s1, L1 s4, L2 s8, L3 s6, L4 s4, L5 s8, L6 s4, L7 s4 (`/home/user/work/radhouse/c_s<N>`); у остальных дублей были «взорвАлась», «окнА», «дверИ», «Уйди», «банОк», «объявЯт», «суткИ».

## Звук

- `tools/music.py` — партитура в ми миноре: тихое утро и челеста, обрыв на взрыве (удар, литавра, тарелка), гул и сердцебиение, удар на «Не надо», холодное тремоло снаружи, остинато первого шага с ударом на каждую закрытую вещь, ксилофон вниз по ступенькам, три литавры на «каждая стена», колокольчики на воду и банки, напряжённый удар на йод, соль мажор у радио, C → B7 в конце, который ведёт в начало круга.
- `tools/fx.py` — эффекты: птицы, взрыв, дребезг стекла, сигнал телефона, шаги, скрип двери, ветер, дозиметр (чаще, пока пыль летит к дому, реже в погребе), хлопки окна и двери, засов, заслонка, вентилятор с остановкой, пылинки по стеклу, люк, ступеньки, бульканье бутылки, банки, флакон, таблетки, радио, часы; фон — тихий дом и ветер за стеной.
- `tools/mix.py` — сведение под рассказчика: музыка ниже голоса и уходит вниз, пока он говорит; эффекты тише него, взрыв — на 3 LU тише голоса; хвост переносится в начало; −14 LUFS, пик не выше −2 dBTP.

## Сборка

```
npm install
python3 tools/voice.py voice/script.json build/voice.wav L0=<папка нарезанного дубля> L1=… …   # голос и слова
node render.mjs cues build/cues.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav ../build/stems && cd ..
node render.mjs video out/pic.mp4 4
ffmpeg -i out/pic.mp4 -i build/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -ar 48000 -shortest -movflags +faststart out/vzryv-aes-doma.mp4
```
