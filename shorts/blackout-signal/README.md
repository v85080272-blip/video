# «Пропала связь» (плоская 2D, блэкаут ч.5)

Вертикальный мультик 1080×1920, 60 к/с, около 45 с, серия «Как выжить», мини-сезон «Блэкаут» (план сезона —
`../BLACKOUT-SEASON.md`). Та же квартира на 20-м этаже, охотник в тельняшке, лайка Пурга, рассказчик серии.

## Сюжет

Десятый день без света, вышки сели, «нет сети». Ошибка: верить слухам у подъезда. Факт: новости никуда не
делись, их передают по радио. Три шага: радио на батарейках или с ручкой, официальные сообщения, а не соседи; один
человек в другом городе, через которого вся семья передаёт новости; заряжать телефон в машине только на улице (в
гараже мотор отравит угарным газом). Поворот: вечером по радио сказали, где раздают воду, а сосед всё ещё ждал, когда
загрузится лента. Вопрос: «А у тебя дома есть радио?».

Текст и источники фактов — `voice/script.json`.

## Сцены (набросок раскадровки, до сборки выбрать по 3–5 вариантов на сцену, как в ../blackout-week/STORYBOARD.md)

- **Обложка:** охотник крутит ручку радио, Пурга наклонила голову к динамику; «НЕТ СЕТИ», плашка «ЧАСТЬ 5».
- **Крючок:** телефон крупно: палки сети гаснут по одной, «нет сети», карта города, где гаснут вышки.
- **Ошибка:** у подъезда соседи передают слух по цепочке, он искажается в облачках («вода отравлена!»).
- **Шаг 1:** радио с ручкой-динамо, шкала настройки, волны идут от вышки радиостанции.
- **Шаг 2:** схема: семья из пяти точек, все линии сходятся к одной точке в другом городе.
- **Шаг 3:** машина во дворе с открытым окном, телефон на зарядке ✓; рядом гараж с машиной внутри, серое облако ✗.
- **Поворот:** по радио «вода — школа №5»; герой с канистрами идёт мимо соседа, который трясёт телефон.
- **Код:** герой, собака, HUD и чертёж из ../blackout-week, новое: радио, вышки, схема контактов, машина.

## Как собрать

1. Скопировать код картинки и звука из `../blackout-week` (src, tools, render.mjs, fonts, package.json, voice/takes.sh с
   новым `OUT`), заменить сцены в `src/main.js` и `tools/music.py`.
2. Голос — рассказчик серии по `voice/script.json`, как в README `../blackout-week`. До озвучки тайминги по
   `node ../blackout-week/tools/fake_words.mjs voice/script.json build/words.json`.
3. Сборка, сведение −14 LUFS, проверка `qa/check_clip.py` — как в `../blackout-week/README.md`.
