# «Правда или миф», №3 «Гроза» (2D)

Короткая викторина по правилам выгрузки Студии (10.11, `../STATS.md`): светлый первый кадр (солнечный луг, с края
надвигается туча, «ПРАВДА ИЛИ МИФ?», три карточки, лента «2 ИЗ 3 МОГУТ УБИТЬ» — с 0 с), ≈37 с, «правда» последняя.

1. Гроза — спрячься под деревом → **МИФ**: молния бьёт в самое высокое, ток идёт по земле (удар в дерево, ток
   расходится по траве); уходи в здание (охотник уходит к дому).
2. Молния не бьёт дважды в одно место → **МИФ**: в высокие башни — десятки раз в год (башня, счётчик ударов; плашка
   «Останкино: десятки молний в год»).
3. В машине с крышей молния не страшна → **ПРАВДА**: ток идёт по металлическому кузову в землю, а не через шины
   (кузов светится; плашка «кабриолет и мотоцикл — не защита»). Пурга в машине.

Источники — в `voice/script.json` (`note`): архив NWS «Lightning myths», AAA, mos.ru и m24 об Останкинской башне (число
ударов не озвучено — разные источники дают от 25–30 до 40–50 в год, сказано «десятки»).

Места — `src/storm.js` (луг под тучей, дерево, молнии, ток по земле, башня, дом, машина, карточки); музыка — та же
викторина, что в №1; звуки — `thunder`, `rain`, `steps_run` из `tools/fx.py`.

Статус: собрано 10.11, `qa/check_clip.py` — ошибок нет (−14,2 LUFS, пик −1,9 dBTP, 37,4 с, 48 слов); замечания — три
паузы по 1,6–1,7 с перед ответами (нарочно). Голос (`/home/user/work/myth-storm`): L0 s5, L1 s6, L2 s2, L3 s2, L4 s4 (у
двух дублей «башнИ»), L5 s5, L6 s3, L7 s3. Название (пиар-агент): «Гроза? НЕ ПРЯЧЬСЯ ПОД ДЕРЕВОМ! ⚡».
