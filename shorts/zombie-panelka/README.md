# Зомби в панельке · Серия 1

Вертикальный мультик 1080×1920, 30 к/с, 77,8 с (версия 2 с новым рассказчиком; версия 1 — 75,9 с). Формат «гайд по выживанию на ты»: рассказчик ведёт зрителя по пяти шагам за десять минут до того, как в доме погаснет свет, а в конце за дверью оказывается баба Валя с пирожками и забинтованной рукой. Финал «Ты бы открыл?» и «Часть 2 — скоро» — крючок для комментариев и продолжения.

Каждый кадр рисует код (Node + `@napi-rs/canvas`), все звуки и музыка синтезированы в numpy, сторонней музыки и сэмплов нет.

## Голоса

- **Рассказчик, версия 2** — Qwen3-TTS VoiceDesign без клонирования, как баба Валя: `voice/narrator_takes.sh` читает весь сценарий одним запросом по описаниям из `voice/narrator_prompts.tsv` с разными сидами. Выбран дубль p4s1 («уставший выживший»: низкий, около 106 Гц, ровный, с хрипотцой, вполголоса), ближе всех к рассказчику референса (≈100–112 Гц, ровная интонация). У двух дублей из восьми голос пропустил «Дверь» в «Первое. Дверь.», у одного — последнюю реплику, поэтому каждую реплику сверяем по CER.
- **Рассказчик, версия 1** — клон Qwen3-TTS из «Тайн истории» (референс `d2_s43.wav`, ветка `claude/history-facts-reels-i5tnav`, папка `shorts/history-facts/`); vla он показался роботизированным, а UTMOS ставил ему 4,30 против 3,71 у понравившейся Вали, так что UTMOS тут не мерило.
- **Ударения** проверяет тред «Проверка ударений и звука» (его `qa/` в общей папке). У голоса А она нашла «невИдимкой» (так ошибались четыре голоса из пяти), «ваннУ» и «Они». «Стань невидимкой» заменено на «Стань невидимым»: эту форму голоса ударяют верно. Реплики L8 и L12 перечитаны клоном того же голоса (Qwen3 Base в режиме ICL, референс — его же L13–L14, по четыре сида), проверка выбрала дубли с верными ударениями, а `tools/patch_lines.py` вставил их вместо исходных. Короткое «они» в «Внизу — они» под музыкой звучало как «Они» во всех дублях, поэтому L17 теперь «Лифт — ловушка. Внизу — зомби.», перечитана тем же клоном с шестью сидами, а дубль выбран проверкой с подложкой из музыки финала (`--bed`).
- `tools/cut_voice.py` режет дубль на реплики L1–L21: сценарий сопоставляется со словами faster-whisper по буквам (склеенные «скотом» и разорванные «кто -то» не мешают), вдох перед репликой, если он есть, сохраняется в `B_<id>.wav`, а слова Whisper кэшируются. `tools/score_voice.py` считает UTMOS.
- **Баба Валя** — Qwen3-TTS VoiceDesign (`voice/valya_takes.sh`: два описания по четыре сида), выбран дубль b23 (лучший UTMOS, CER 0, F0 около 180 Гц). `tools/valya_voice.py` приглушает её «через дверь» (НЧ-фильтр, резонанс полотна, эхо подъезда), пишет время слов и огибающую рта.
- `tools/layout.py` раскладывает реплики по таймлайну с паузами под гэги, ставит вдохи рассказчика в паузы, где они помещаются, и пишет `build/timing.json`.

## Картинка

- `src/draw.js`, `src/lib.js` — холст, псевдо-3D заливки, обводка, тени, лёгкие пружины.
- `src/hero.js`, `src/cat.js`, `src/granny.js`, `src/zombie.js` — персонажи (руки-шланги, мимика, моргание, рот по огибающей).
- `src/sets/` — двор и дом снаружи, квартира, кухня, ванная, подъезд, дом в разрезе, глазок с «рыбьим глазом».
- `src/text.js` — заголовки, цифры шагов с подтёками, субтитры по словам.
- `src/main.js` — якоря по словам озвучки, 33 сцены, камера, тряски, вспышки, таймер и список звуковых меток `cues()`.

Под Skia (`@napi-rs/canvas`) заливка `destination-out` под `translate()` теряет часть прямоугольника, поэтому дыры в темноте рисуются в абсолютных координатах (`darkness()` в `src/main.js`).

## Звук

- `tools/sfx.py` — 55 эффектов: мяу и мурчание кота, кастрюля с крутящейся крышкой, ключ, задвижка, скрежет шкафа, вода, удары, сирены, рык толпы, когти по двери, сердце и т. д.
- `tools/music.py` — музыка в ре миноре: тиканье часов и бас, темп подогнан под каждый шаг так, чтобы удар цифры приходился на сильную долю; на каждом шаге добавляется слой; перед ударом — провал и обратный «всос»; кастрюля обрывает музыку; разгон и отсчёт вдвое быстрее, потом «плёнка останавливается», когда гаснет свет. После темноты — тёплый аккорд на «Ты успел», тёмный гул и расстроенная музыкальная шкатулка под бабу Валю, которая проседает при появлении тени и умирает на крови.
- `tools/mix.py` — голос (ФВЧ, лёгкий провал на 300 Гц и мягкий компрессор: подъём присутствия и быстрая компрессия делали синтетический голос ещё искусственнее), эффекты и музыка, музыка и длинные эффекты приседают под голос; громкость −14 LUFS, true peak не выше −2 dBTP (AAC добавляет до 1,4 дБ на ударах), в конце затухание 0,9 с.

## Сборка

```bash
npm install
python3 -m pip install numpy scipy soundfile faster-whisper   # для голоса и звука
bash voice/narrator_takes.sh                      # дубли рассказчика (Qwen3-TTS VoiceDesign, qwentts.cpp)
python3 -I tools/cut_voice.py /home/user/work/zombie/voice2/takes/p4s1.wav voice/script.json /home/user/work/zombie/voice2/c_p4s1
python3 tools/patch_lines.py /home/user/work/zombie/voice2/c_p4s1 /home/user/work/zombie/voice2/c_A L8=<дубль L8> L12=<дубль L12> L17=<дубль L17>
python3 tools/layout.py /home/user/work/zombie/voice2/c_A build/valya/valya.wav build/valya/valya_words.json build/timing.json
node render.mjs stills tmp/st 0.6 5.2 66.3        # проверочные кадры
node render.mjs cues build/cues.json              # якоря и звуковые метки
node render.mjs video build/picture.mp4 4         # картинка, 4 процесса
python3 tools/music.py build/cues.json build/music.wav
python3 tools/mix.py build/mix.wav
ffmpeg -i build/picture.mp4 -i build/mix.wav -map 0:v -map 1:a -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -movflags +faststart -shortest out/zombie-panelka-seriya1-v2.mp4
```

Картинка рендерится около 3 минут на 4 ядрах, музыка и сведение — меньше минуты.
