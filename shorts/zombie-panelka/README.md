# Зомби в панельке · Серия 1

Вертикальный мультик 1080×1920, 30 к/с, 75,9 с. Формат «гайд по выживанию на ты»: рассказчик ведёт зрителя по пяти шагам за десять минут до того, как в доме погаснет свет, а в конце за дверью оказывается баба Валя с пирожками и забинтованной рукой. Финал «Ты бы открыл?» и «Часть 2 — скоро» — крючок для комментариев и продолжения.

Каждый кадр рисует код (Node + `@napi-rs/canvas`), все звуки и музыка синтезированы в numpy, сторонней музыки и сэмплов нет.

## Голоса

- **Рассказчик** — тот же клон Qwen3-TTS, что в «Тайнах истории» (референс `d2_s43.wav` и сервер из пайплайна «Тайн истории»: ветка `claude/history-facts-reels-i5tnav`, папка `shorts/history-facts/`). Сценарий читается целиком одним запросом, три сида; выбран третий. `tools/cut_voice.py` режет дубль на реплики L1–L21 по словам faster-whisper, `tools/score_voice.py` считает UTMOS и CER.
- **Баба Валя** — Qwen3-TTS VoiceDesign (`voice/valya_takes.sh`: два описания по четыре сида), выбран дубль b23 (лучший UTMOS, CER 0, F0 около 180 Гц). `tools/valya_voice.py` приглушает её «через дверь» (НЧ-фильтр, резонанс полотна, эхо подъезда), пишет время слов и огибающую рта.
- `tools/layout.py` раскладывает реплики по таймлайну с паузами под гэги и пишет `build/timing.json`.

## Картинка

- `src/draw.js`, `src/lib.js` — холст, псевдо-3D заливки, обводка, тени, лёгкие пружины.
- `src/hero.js`, `src/cat.js`, `src/granny.js`, `src/zombie.js` — персонажи (руки-шланги, мимика, моргание, рот по огибающей).
- `src/sets/` — двор и дом снаружи, квартира, кухня, ванная, подъезд, дом в разрезе, глазок с «рыбьим глазом».
- `src/text.js` — заголовки, цифры шагов с подтёками, субтитры по словам.
- `src/main.js` — якоря по словам озвучки, 33 сцены, камера, тряски, вспышки, таймер и список звуковых меток `cues()`.

Под Skia (`@napi-rs/canvas`) заливка `destination-out` под `translate()` теряет часть прямоугольника, поэтому дыры в темноте рисуются в абсолютных координатах (`darkness()` в `src/main.js`).

## Звук

- `tools/sfx.py` — 55 эффектов: мяу и мурчание кота, кастрюля с крутящейся крышкой, ключ, задвижка, скрежет шкафа, вода, удары, сирены, рык толпы, когти по двери, сердце и т. д.
- `tools/music.py` — музыка в ре миноре: тиканье часов и бас, темп подогнан под каждый шаг так, чтобы удар цифры приходился на сильную долю; на каждом шаге добавляется слой; перед ударом — провал и обратный «всос»; кастрюля обрывает музыку; разгон и отсчёт вдвое быстрее, потом «плёнка останавливается», когда гаснет свет. После темноты — тёплый аккорд на «Ты успел», тёмный гул и расстроенная музыкальная шкатулка под бабу Валю, которая проседает при появлении тени и умирает на крови.
- `tools/mix.py` — голос (ФВЧ, эквалайзер, компрессор), эффекты и музыка, музыка и длинные эффекты приседают под голос; громкость −14 LUFS, true peak не выше −1,5 dBTP.

## Сборка

```bash
npm install
python3 -m pip install numpy scipy soundfile faster-whisper   # для голоса и звука
# голос: дубли рассказчика → tools/cut_voice.py → tools/layout.py → build/timing.json, build/valya/*
node render.mjs stills tmp/st 0.6 5.2 66.3        # проверочные кадры
node render.mjs cues build/cues.json              # якоря и звуковые метки
node render.mjs video build/picture.mp4 4         # картинка, 4 процесса
python3 tools/music.py build/cues.json build/music.wav
python3 tools/mix.py build/mix.wav
ffmpeg -i build/picture.mp4 -i build/mix.wav -map 0:v -map 1:a -c:v libx264 -preset slow -crf 17 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -movflags +faststart -shortest out/zombie-panelka-seriya1.mp4
```

Картинка рендерится около 3,5 минуты на 4 ядрах, музыка и сведение — меньше минуты.
