# «Третий день в холоде» (плоская 2D, блэкаут ч.5)

Вертикальный мультик 1080×1920, 60 к/с, около 47 с, серия «Как выжить», мини-сезон «Блэкаут» (план сезона —
`../BLACKOUT-SEASON.md`). Продолжение ч.4 (`../blackout-winter`) с того места, где она кончилась: третье утро без света,
вода в ванне из ч.1 замёрзла, в квартире +8. Тот же охотник во всех слоях одежды, лайка Пурга с фонариком, рассказчик серии.
Запрос vla от 31.10.2026: «логично и поэтапно: закончили на ванной, с неё и продолжить, что делать дальше, когда холодно и нет света».

## Сюжет

Ошибка: сосед зовёт согреться водкой, а алкоголь только кажется тёплым, тепло из тела уходит быстрее. Если холод не уходит,
из квартиры пора уходить, но по плану. Три шага: есть и пить регулярно (еда помогает греться), лёд из ванны — для туалета;
узнать, где пункт обогрева (соседи, радио на батарейках); собрать документы, лекарства, тёплые вещи, фонарик, перекрыть воду и
газ, написать родным, куда идёшь. Поворот: двадцать этажей вниз пешком за фонариком Пурги, а в пункте обогрева ей первой
налили тёплой каши. Вопрос: «А ты знаешь, где у тебя ближайший пункт обогрева?».

Текст и источники фактов (CDC, FEMA) — `voice/script.json`.

## Сцены

- **Обложка:** охотник с рюкзаком и Пурга с фонариком на кухне в инее; «ТРЕТИЙ ДЕНЬ В ХОЛОДЕ», плашка «ЧАСТЬ 5 · ПОРА УХОДИТЬ».
- **Крючок:** ванна со льдом (как в конце ч.4), термометр падает с +12° до +8°.
- **Ошибка:** охотник на тепловизоре с бутылкой: красный крест, лента «АЛКОГОЛЬ НЕ ГРЕЕТ», кожа светится «тёплой», потом тепло
  уходит стрелками во все стороны и тело остывает.
- **План:** дом в разрезе, маршрут с 20-го этажа по лестнице и через двор к школе с тёплыми окнами — «ПУНКТ ОБОГРЕВА».
- **Шаг 1:** консервы и хлеб на кухне, Пурга ест из миски; ведро со льдом из ванны у туалета — «ЛЁД — ДЛЯ ТУАЛЕТА».
- **Шаг 2:** радио на батарейках, бегущая строка «пункт обогрева открыт в школе № 12».
- **Шаг 3:** документы, лекарства, свитер и фонарик влетают в рюкзак, чек-лист; кран газа поворачивается поперёк трубы; сообщение родным.
- **Поворот:** лестница в разрезе, впереди Пурга с лучом фонарика, счётчик этажей; тёплый спортзал с раскладушками, волонтёр
  наливает кашу сначала Пурге.
- **Код:** квартира, герой, собака, иней, пар и тепловизор из ч.4; новое: тело на тепловизоре, маршрут, ведро со льдом,
  радио, рюкзак, лестница, пункт обогрева.

## Голос

Рассказчик серии, как в ч.1–4: `voice/takes.sh` (дубли в `/home/user/work/blackout-cold`). У строки может быть поле `tts` —
текст, который читает голос, если он отличается от субтитров: в L6 «пурга» со строчной, иначе голос говорит «пУрга» (ч.4).

## Сборка

Как у ч.2 (`../blackout-week/README.md`):

```
npm install
python3 tools/voice.py voice/script.json build/voice.wav L0=<папка нарезанного дубля> L1=… …   # голос и слова
node render.mjs cues build/cues.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav ../build/stems && cd ..
node render.mjs video out/pic.mp4 4
ffmpeg -i out/pic.mp4 -i build/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -ar 48000 -shortest -movflags +faststart out/tretiy-den-v-holode.mp4
```

Статус: сценарий, картинка и музыка готовы, идёт озвучка.
