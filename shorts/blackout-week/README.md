# «Неделя без света» (плоская 2D, блэкаут ч.2)

Вертикальный мультик 1080×1920, 60 к/с, около 44 с, серия «Как выжить». Продолжение «Погас свет, ты на 20-м этаже»
(`../blackout-flat`): та же квартира на 20-м этаже, охотник в тельняшке, лайка Пурга с фонариком, рассказчик серии.
Запрос vla от 31.10.2026: «продолжение к 1 серии, многим зашёл этот формат».

Сюжет: прошла неделя, света так и нет. Соседи несут домой мангалы и газовые горелки, а от них угарный газ без цвета и
запаха. Три шага: никакого огня в квартире, еда без готовки (консервы, хлеб, орехи); мясо, молоко и яйца из
холодильника в мусор (без холода через 4 часа их есть опасно); связь — писать, а не звонить. Поворот: на седьмой
день свет дают, герой заранее выдернул технику из розеток, а у соседа от скачка сгорел телевизор. Конец: призыв
подписаться и вопрос «А сколько ты продержишься без света?».

Текст и источники фактов — `voice/script.json`, раскадровка с вариантами сцен — `STORYBOARD.md`.

## Голос

Рассказчик «уставший выживший» (Qwen3-TTS Base, клон, как в ч.1): `voice/takes.sh`. Образец `ref.wav` и `ref.txt`
лежат на странице «Облако мультиков» (https://claude.ai/artifact/F8DKdrunMWqPDT4DqFQRp5, `golosa/rasskazchik/`);
их кладут в папку из `REF`. Модели качаются с Hugging Face, поэтому озвучивать нужно в облачной среде «Голоса».
Пока голоса нет, картинка идёт по оценке темпа: `node tools/fake_words.mjs` пишет `build/words.json` по слогам
(0,145 с на слог и паузы: так оценка совпадает с настоящим голосом ч.1 с точностью до 0,3 с), и черновик собирается с субтитрами без звука.

## Сборка

Как у ч.1 (`../blackout-flat/README.md`):

```
npm install
python3 tools/voice.py voice/script.json build/voice.wav L0=<папка нарезанного дубля> L1=… …   # голос и слова
node render.mjs cues build/cues.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav ../build/stems && cd ..
node render.mjs video out/pic.mp4 4
ffmpeg -i out/pic.mp4 -i build/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -ar 48000 -shortest -movflags +faststart out/nedelya-bez-sveta.mp4
```

Статус: озвучено и собрано 31.10, `qa/check_clip.py` без ошибок (−14,1 LUFS, пик −2,0 dBTP, 45,3 с).

Дубли лежат в `/home/user/work/blackout-week/c_s<N>` (6 зёрен). В ролике: L0 из дубля s1, L1 s3, L2 s3, L3 s2, L4 s2, L5 s2, L6 s4, L7 s2.
