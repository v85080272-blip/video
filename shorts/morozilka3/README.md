# Морозилка, серия 3 «Побег»

Крючок с первого кадра: красная тревога, штамп «ПЛАН ПОБЕГА», Сырник: «Мы сбегаем! Сегодня!». Пельмень не верит, Сырник прыгает прямо в руку («Свобода!»), за кадром шипит сковородка, и его возвращают подгоревшим: «Там! Сковородка!». Пельмень: «С возвращением.»

Ярче, чем серии 1–2: насыщенная палитра, вращающиеся лучи за крупными планами, наезды камеры на каждой реплике, вспышка на прыжке. Голоса: `python tts.py <папка>` (RHVoice, apt `rhvoice rhvoice-russian`), высота и темп каждой реплики задаются в `story.json`. Сборка как у серии 1 (см. `shorts/morozilka/README.md`).
