# «Операция спасения» №1 «Девочка и щенок в тайге»

Первый выпуск нового формата (12.11). Он придуман после того, как зрителям понравились «Дети в пещере»: настоящая
история спасения, и главный спасатель — зритель. Правила формата — в `shorts/RESCUE.md`.

**История.** Якутия, лето 2014 года. Трёхлетняя девочка ушла в тайгу за отцом, с ней был только щенок. Дома думали,
что она с отцом, и хватились через несколько дней. Нашли её на двенадцатый день, живой, в высокой траве.

Источники: Moscow Times, SBS, Siberian Times по OutdoorHub, life.ru, snob.ru. Они расходятся в трёх вещах: 11 или
12 дней, 3 года или почти 4, кличка щенка. В ролике то, в чём сходится большинство, а кличку не называем. Полная
справка лежит в поле `note` файла `voice/script.json`.

## Как сделано

**Сцены** нарисованы плоскими фигурами в `src/taiga.js`:
- летняя тайга с лиственницами и холмами, трава выше роста;
- девочка (стоит, идёт, сидит в траве, машет рукой) и щенок (`src/dog.js`);
- вертолёт, спасатели в оранжевых жилетах, деревня с забором;
- след лап, ягоды, ручей;
- памятник.

Все герои стоят выше субтитров (SUB.y 1500), чтобы текст их не закрывал.

**Решения и время** — в `src/main.js`:
- `Q` задаёт два решения: подписи кнопок, верный ответ и окно отсчёта в словах;
- `T` задаёт метки для музыки: начала решений, «нашли», финал.

**Музыка** (`tools/music.py`): светлая тема спасения. На решениях она замолкает, на верных ответах звучат яркие
акценты. Под всей историей до финала поют птицы (новый звук `FX['birds']` в `tools/fx.py`).

**Голос** — наш локальный рассказчик (как в «Реальных историях»), шесть дублей. Для каждой фразы взят дубль, где все
ударения верные, в том числе с музыкой под голосом (`qa/pick_take.py --asr --bed`):

| Фраза | Дубль | Что было у других дублей |
|---|---|---|
| L0 «Девочке три года…» | s1 | у одного, похоже, «щЕнок» |
| L1 «Её хватились…» | s4 | у двух «цепьЮ» |
| L2 «Два! Трава выше роста…» | s1 | у четырёх «тАйгу», у одного «пЕшком» |
| L3 «Девятый день…» | s6 | ошибок нет во всех дублях |
| L4 «Два! Собаки-ищейки…» | s5 | у двух «Ищейки» |
| L5 «Двенадцать дней в тайге!..» | s2 | у остальных «пИла» или «рЕчную» |
| L6 «В Якутии теперь стоит памятник…» | s1 | у трёх «стОит» |

Омографа избегали заранее: «Дома хватились» (дОма / домА) заменено на «Её хватились».

```bash
node render.mjs cues build/cues.json
cd tools && python3 music.py ../build/cues.json ../build/music.wav && python3 mix.py ../build/cues.json ../build/music.wav ../build/mix.wav ../build/voice.wav && cd ..
node render.mjs video build/video.mp4 3
ffmpeg -i build/video.mp4 -i build/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 256k -ar 48000 -af "afade=t=out:st=44.7:d=0.5" -shortest -movflags +faststart out/devochka-i-shchenok.mp4
ffmpeg -i out/devochka-i-shchenok.mp4 -frames:v 1 -q:v 2 out/devochka-i-shchenok-cover.jpg
```

Статус: готово 12.11. Проверка `qa/check_clip.py` прошла без ошибок:
- длительность 45,2 с;
- громкость −14,1 LUFS, пик −2,0 dBTP;
- ударения верные во всех 72 словах из двух и более слогов.

Есть два замечания: паузы по 1,7 с на 12,4 и 24,8 с. Это окна «РЕШАЙ», они там нарочно.

Название для YouTube: «Ребёнок потерялся в тайге? НЕ ИЩИ С ВЕРТОЛЁТА! 🐶». Остальные тексты (описание, закреп,
подпись для Reels) лежат на странице сериала в Кинозале.
