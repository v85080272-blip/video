# «Правда или миф», №2 «Мифы про холод» (2D)

Короткая викторина по правилам выгрузки Студии (10.11, `../STATS.md`): светлый первый кадр (снежный день, «ПРАВДА ИЛИ
МИФ?», три карточки, лента «2 ИЗ 3 — ОПАСНЫЙ МИФ» — всё с 0 с), ≈40 с, «правда» в этот раз посередине. Перед каждым ответом
зритель угадывает: кнопки «ПРАВДА / МИФ», отсчёт, музыка замолкает.

1. Замёрз — выпей водки → **МИФ**: тепло только кажется, тело остывает быстрее (термометр тела падает); лучше горячий
   сладкий чай.
2. Несколько тонких слоёв греют лучше одной толстой куртки → **ПРАВДА**: между слоями тёплый воздух; жарко — сними один
   и не вспотеешь (схема «три тонких / одна толстая», один слой улетает).
3. Обморозил руки — разотри снегом → **МИФ**: снег царапает и морозит сильнее; грей в тёплой (не горячей) воде, не три.

Источники — в `voice/script.json` (`note`): архив CDC, Mayo Clinic, памятка штата Индиана. Температура воды не названа
(Mayo даёт 40–43 °C, другие — меньше), только «тёплая, не горячая».

Места и вещи — `src/story.js` (снежный день, карточки, слои, кружка, миска, термометр), охотник и Пурга — `src/hunter.js`,
`src/dog.js`; музыка — та же викторина, что в №1 (`tools/music.py`). Сборка — как в `../blackout-week/README.md`.
