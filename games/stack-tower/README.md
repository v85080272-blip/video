# Башня

Мини-игра для роликов, сделанная скиллами [game-creator](https://github.com/opusgamelabs/game-creator) (шаблон Phaser 4). Блок ездит над башней, тап ставит его, всё, что свисает, отрезается и падает. Идеальное попадание даёт серию «ИДЕАЛЬНО ×N», и после 4 подряд блок понемногу растёт обратно.

## Запуск

```bash
npm install
npm run dev
```

- `http://localhost:3000/` — играть самому (тап или пробел).
- `http://localhost:3000/?demo&seed=7` — автопилот крутит раунды с вопросом «На каком этаже упадёт башня?». Удобно для записи экрана.

## Ролик одной командой

```bash
npm run capture -- --seed 7
npm run capture -- --seed 12 --floor 24
```

Кладёт `output/tower-seed7.mp4`: 1080×1920, 60 к/с, со звуком. Игра идёт покадрово, а не в реальном времени, поэтому клип плавный на любой машине, и один и тот же сид всегда даёт один и тот же ролик. `--floor` задаёт, на каком этаже башня упадёт (по умолчанию от 19 до 25, ролик около 20 секунд). Звук синтезируется из тех же нот, что играют в браузере (`src/core/Tones.js`).

Для захвата нужен Chromium для Playwright и ffmpeg.

## Устройство

- `src/core/Tower.js` — детерминированная симуляция башни, без Phaser.
- `src/core/Autopilot.js` — бот для ролика: в основном чистые попадания, пара нервных срезов перед концом и промах на заданном этаже.
- `src/scenes/GameScene.js` — изометрическая отрисовка, камера, тексты, ввод.
- `scripts/capture.mjs` — покадровая запись и сборка MP4.
