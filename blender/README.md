# 3D-ролики в Blender

«1 г … 1 т против арбуза» в настоящем 3D: Blender (Cycles) рисует, pybullet
считает удар и разлёт кусков, подписи и звук накладываются тем же стилем,
что и в Залип Лабе.

## Что нужно

Python 3.11, ffmpeg, Node и Chromium для Playwright. Blender ставить не надо:
он идёт пакетом `bpy` прямо в Python.

```bash
python3.11 -m venv .venv-blender
.venv-blender/bin/pip install bpy==5.0.1 pybullet numpy
```

## Как собрать ролик

1. Каждый раунд (0 = 1 г … 4 = 1 т) рендерится отдельно в свою папку:

   ```bash
   for r in 0 1 2 3 4; do
     .venv-blender/bin/python blender/melon3d.py $r out/r$r --res 720 --samples 5
   done
   ```

   `--frames 0,30,60` рендерит только эти кадры (для проверки),
   `--res 360 --samples 2` даёт быстрый черновик. На 4 ядрах чистовик
   720×1280 идёт около 7–9 секунд на кадр, весь ролик около часа.

2. Склейка с подписями и звуком в 1080×1920:

   ```bash
   PLAYWRIGHT=/path/to/node_modules/playwright node blender/comp.cjs job.json
   ```

   ```json
   { "rounds": ["out/r0", "out/r1", "out/r2", "out/r3", "out/r4"],
     "out": "arbuz-3d.mp4", "work": "out/comp",
     "fonts": "node_modules/@fontsource/rubik/files", "crf": 21 }
   ```

## Как устроено

- Арбуз: эллипсоид с приплюснутым дном. Корка рисуется полосами вдоль длинной
  оси, срезы показывают тёмную кожуру, белую прослойку, красную мякоть и
  косточки. Каждая вершина помнит своё место в целом арбузе (атрибут `rest`),
  поэтому узор не «плывёт», когда кусок летит.
- Разлом: ячейки Вороного, нарезанные плоскостями через `bmesh.bisect_plane`.
  Чем тяжелее шар, тем больше ячеек и тем гуще они у точки удара.
- Физика: pybullet. В момент касания целый арбуз заменяется кусками, и они
  получают толчок от точки удара. «Треснул» не считается физикой: три дольки
  просто расходятся на несколько градусов.
- Сок: капли летят по параболе, тянутся по скорости и растекаются пятнами на полу.
- Замедление: вокруг удара время идёт в 4–7 раз медленнее.
- Фон: студийная стена со светящимся «северным сиянием», которое медленно
  движется.
