# Искра в 3D — модель из нейросети по референсам владельца

15–16.11 владелец: «она всё равно выглядит страшненько — нельзя ещё больше текстур?» и прислал 3D-референсы
(`branding/iskra-3d/`). Прежняя Искра из `rig.py` была собрана из кода: гладкие трубки и нарисованное лицо на шаре.
Поэтому она выглядела куклой, и текстуры этого не исправляли.

Теперь модель делает нейросеть «картинка → 3D» Microsoft TRELLIS.2 (бесплатная демо на Hugging Face, ZeroGPU).
Владелец разрешил отправить туда вид анфас (16.11).

## Файлы

| Файл | Что это |
|---|---|
| `input_front.png` | вход: вид анфас из `branding/iskra-3d/01-iskra-rakursy.png` |
| `iskra_trellis2.glb` | ответ TRELLIS.2: сетка ~194 тыс. вершин, текстура 2048 |
| `iskra_rigged.blend` | после `prep.py` и `rig_glb.py`: 1,68 м, ноги на полу, лицом к −y, 85 тыс. граней, скелет, текстуры упакованы |
| `preview.jpg` | спереди, ¾, сзади; шаг, присед, рука вперёд, сидя |

## Как сделано

```bash
pip install gradio_client
python3 gen.py input_front.png iskra_t2 0 1024          # ~45 с; нужен токен Hugging Face (сохранён в среде «голоса» для microsoft-trellis-2.hf.space)
/home/user/work/bpyenv/bin/python prep.py -- $PWD/iskra_t2.glb $PWD/iskra_body.blend $PWD/ob   # сварить швы, убрать обрывки, масштаб, decimate 0.3
/home/user/work/bpyenv/bin/python rig_glb.py -- $PWD/iskra_body.blend $PWD/iskra_rigged.blend    # скелет + веса
/home/user/work/bpyenv/bin/python posetest.py -- $PWD/iskra_rigged.blend $PWD/pt                 # пробные позы
```

- Скелет повторяет кости и соглашения `rig.py`: L — на −x, roll 0; бедро +X — назад, голень +X — сгиб колена,
  плечо −X — вперёд, предплечье −X — сгиб локтя, spine +X — наклон вперёд. Поэтому позы и ходьба из
  `posyolok.py` подходят без переделки.
- Суставы сняты с ортографических видов спереди и сбоку с сеткой 10 см (`prep.py`).
- Веса — автоматические (bone heat); у всех вершин есть кость.

## Что ещё не так

- Лицо вблизи: правый глаз целиком закрыт прядью (бирюзовой и фиолетовой), рот открыт в широкой улыбке и смазан.
  Издалека не видно, на крупном плане заметно.
- План: отдельно сгенерировать голову по крупному «НЕЙТРАЛЬНО» из `02-iskra-mimika.png` и поставить вместо головы
  тела; шов спрячет высокий воротник. Первая попытка дала плоскую карточку: на вход ушло RGB на чёрном фоне.
  Нужно RGBA с прозрачным фоном (`head_rgba.png` в `gen.py` пропускает предобработку).
- Бесплатная квота ZeroGPU — около 4 мин в день, на 16.11 закончилась: две генерации тела и головы ~2 мин.
  Следующая — после ~04:00 UTC 17.11.
